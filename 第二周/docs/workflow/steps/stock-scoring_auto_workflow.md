> **负责人**：师文池
> 对应流水线环节：② 量化打分
> 前置文档：`main_auto_workflow.md`、`docs/data-collection_auto_workflow.md`

---

## 目标

对数据收集阶段产出的股票池进行多维度打分，输出 Top N 选股结果（含三大维度得分和各项小分明细）、个股分析报告、买卖操作建议。

**核心架构：基本面筛选 + 三维度打分**
- **基本面**：既是筛选门槛，也是打分因子
- **技术面**：仅用于量化打分排序，不做通过/否决判断
- **资金面**：仅用于量化打分排序（待开发）

---

## 筛选与打分体系

### 第一步：基本面筛选（唯一入围门槛）

系统使用**基本面作为唯一筛选门槛**，只有通过基本面筛选的股票才会进入三维度打分。

| 检查项 | 筛选逻辑 | 行业自适应 |
|--------|----------|------------|
| ST 排除 | 名称含 ST/\*ST/退 则剔除 | 强制 |
| ROE | `roe ≥ thresholds.roe_min` | 国有大行≥10%，股份制银行≥12%，白酒≥18%，半导体≥3% |
| 净利润增长率 | 同比增速 > -30% | 严重下滑则剔除 |
| 自由现金流 | 经营现金流为正 | 金融/半导体豁免（`cash_flow_exempt=True`） |
| 资产负债率 | `debt_ratio ≤ thresholds.debt_ratio_max` | 国有大行≤95%，白酒≤50% |

> **硬约束 H1**：行业自适应必须按二级分类（`industry_level2`）执行，禁止用一级分类或统一阈值。

### 第二步：三维度评分（满分100分）

通过基本面筛选后，系统对每只股票进行三维度量化打分：

---

### 基本面得分（40分）

| 因子 | 分值 | 评分逻辑 | 行业自适应 |
|------|------|----------|-----------|
| ROE | 10分 | 达行业阈值满分，每降1%扣0.5分；低于70%阈值得3分 | 国有大行≥10%，股份制银行≥12%，白酒≥18%，半导体≥3% |
| 营收增速 | 10分 | ≥30%→10分，≥15%→8分，≥5%→6分，≥0%→4分，<0%→2分 | 科技/新能源≥30%，周期≥20%，消费≥10% |
| 自由现金流 | 8分 | 连续3年为正→8分，为正但非连续→5分，为负→0分 | 金融/半导体豁免，给满分 |
| 估值(PE/PB) | 7分 | PE处于行业25%分位以下→7分，50%分位→5分，75%分位→3分 | 金融看PB，科技看PE分位数 |
| 股息率 | 5分 | 达行业阈值→5分，达50%阈值→3分，低于→1分 | 银行≥4%，公用事业≥3%，科技/周期≥1% |

> **代码实现**：`screener.py` → `_calc_fundamental_score()`

---

### 技术面得分（40分）

> 技术面**仅用于打分排序**，不再作为筛选条件。所有通过基本面的股票都会计算技术面得分。

| 因子 | 分值 | 评分逻辑 | 数据来源 |
|------|------|----------|----------|
| 均线多头排列 | 12分 | 股价站稳MA5/MA10/MA20→12分；跌破任一条→6分；全部跌破→0分 | 历史K线（120日） |
| 尾盘拉升 | 8分 | 尾盘涨幅∈[3%,5%]→8分；[1%,3%)→5分；(5%,10%]→3分；其他→0分 | 实时行情+当日K线 |
| 成交量趋势 | 8分 | 近3日连续放大→8分；先放量后缩量→4分；未放大→0分 | 历史K线 |
| 换手率 | 6分 | ∈[5%,10%]→6分；[3%,5%)或(10%,15%]→3分；其他→0分 | 实时行情 |
| 行业热度 | 6分 | 行业近5日涨幅排名前30%→6分；30%-50%→3分；后50%→0分 | 行业指数计算 |

> **硬约束 H5**：即使综合得分很高，如果MA20未站上，投资建议只能是"观察为主"，不能给买入建议。
> **代码实现**：`screener.py` → `_calc_technical_score()`

---

### 资金面得分（20分，待开发）

| 因子 | 分值 | 评分逻辑 |
|------|------|----------|
| 北向资金 | 10分 | 连续3日净流入→10分（待开发，当前默认5分） |
| 主力资金 | 10分 | 净流入为正→10分（待开发，当前默认5分） |

> 当前版本资金面得分默认给 10 分（中性），待数据源接入后启用完整逻辑。
> **代码实现**：`screener.py` → `_analyze_stock()` 中硬编码默认值

## 买卖建议规则

### 买入信号（全部满足）

```
【第一关：基本面筛选 —— 系统自动执行，不满足直接排除】
  ✅ ST/*ST 排除
  ✅ ROE ≥ 行业阈值（按二级分类自适应）
  ✅ 净利润增长率 > -30%
  ✅ 自由现金流为正（金融/半导体豁免）
  ✅ 资产负债率 ≤ 行业上限

【第二关：打分门槛 —— 通过基本面筛选后计算】
  ✅ 基本面得分 ≥ 24/40
  ✅ 技术面得分 ≥ 28/40
  ✅ 综合得分 ≥ 65/100
  ✅ MA20 站上（硬约束 H5，否则降级建议）
```

### 评级与建议映射

| 综合得分 | 评级 | 建议 |
|---------|------|------|
| ≥80分 | ⭐⭐⭐⭐⭐ 优秀 | ✅ 积极建仓：{行业}行业，三维度均衡，均线多头排列，可考虑买入 |
| ≥70分 | ⭐⭐⭐⭐ 良好 | ✅ 积极建仓：{行业}行业，基本面优秀，技术面配合，可逢低布局 |
| ≥60分 | ⭐⭐⭐ 中性 | ⚠️ 谨慎关注：{行业}行业，基本面良好，等待更好时机 |
| ≥50分 | ⭐⭐ 偏弱 | 🔍 观察为主：{行业}行业，基本面中性，MA20未站上，观察为主 |
| <50分 | ⭐ 较差 | ⛔ 回避：{行业}行业，基本面较差，不建议参与 |

### 卖出信号（任一触发）

```
⛔ 止盈：涨幅达 15%-20% → 分批减仓
⛔ 止损：跌破 MA20 且放量（成交量 > 5日均量 × 1.2）→ 立即止损
⛔ 趋势消退：所属行业指数跌破10日均线 → 被动减仓
```

### 仓位建议（凯利公式）

```
建议仓位 = f * 挂钩资金比例

f = (p * b - q) / b

p = 历史胜率（近20次同类信号盈利次数 / 20）
q = 1 - p
b = 赔率（平均盈利 / 平均亏损）

约束：单票仓位上限 30%，下限 10%
```

## 执行步骤

```
Step 1: 接收 data-collection 产出的股票池（含 industry_level2 标签）

Step 2: 基本面筛选
  ├─ 逐股票检查 ST/ROE/利润增长/现金流/负债率
  ├─ 行业自适应阈值匹配
  └─ 通过 → 进入三维度打分；不通过 → 淘汰

Step 3: 三维度打分
  ├─ 基本面(40分)：ROE(10) + 营收增速(10) + 自由现金流(8) + 估值PE(7) + 股息率(5)
  ├─ 技术面(40分)：均线多头排列(12) + 尾盘拉升(8) + 成交量趋势(8) + 换手率(6) + 行业热度(6)
  └─ 资金面(20分)：北向资金(10) + 主力资金(10)（默认值）

Step 4: 综合打分 = 基本面(40) + 技术面(40) + 资金面(20)

Step 5: 排序 → 取 Top N（默认10只）

Step 6: 生成输出
  ├─ 每只股票输出：总得分 + 基本面得分 + 技术面得分 + 资金面得分 + 各项小分明细
  ├─ 评级与建议
  └─ JSON 格式（供 app.py 前端展示）

Step 7: （可选）生成个股分析报告
  ├─ 调用 stock_analyzer/ai_stock_analyzer.py
  ├─ 输出：估值区间、SWOT、买卖建议、凯利仓位
  └─ 报告格式：Markdown
```

## 注意事项

1. **行业阈值不可遗漏**：忘记走行业自适应 = 违反硬约束 H1，银行/半导体会被误杀。
2. **基本面是唯一筛选门槛**：技术面因子（均线/尾盘/量能/换手率）不再作为入围条件，仅用于打分排序。
3. **MA20 不可绕过**：即使综合得分很高，MA20 未站上也只能标记"观察"，不能给买入建议（硬约束 H5）。
4. **凯利仓位有上下限**：计算结果超出 10%-30% 范围时，自动截断到边界值。
5. **错误日志**：单只股票分析异常时会打印错误日志，不会中断整体选股流程。
6. **资金面待开发**：当前资金面评分为默认值，待北向资金/主力资金数据源接入后更新。
