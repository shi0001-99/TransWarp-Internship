# 子流程：确定卖点

> **负责人**：施夏迪+夏可欣
> 对应流水线环节：④ 确定卖点
> 前置文档：`main_auto_workflow.md`、`docs/portfolio-construction_auto_workflow.md`

---

## 目标

基于技术分析规则（MA20 均线、止盈止损、趋势判断）为每只持仓股票确定明确的卖出时机，形成卖点计划，确保"该跑的时候跑得掉"。

---

## 输入

从 `portfolio-construction` 环节接收以下数据：

| 输入项 | 格式 | 说明 |
|--------|------|------|
| 持仓方案 | JSON | 股票代码、持仓占比、买入价、行业标签 |
| 当前行情 | 实时 | 最新价格、成交量、均线位置 |
| 技术指标 | 数值 | MA5、MA10、MA20、成交量、换手率 |

---

## 卖点体系

### 一、核心卖出信号（触发任一即卖出）

#### 1. 止盈卖出

```
触发条件（分级止盈）：

第一级（保守）：
  涨幅 ≥ 10% → 卖出 1/3 仓位

第二级（进取）：
  涨幅 ≥ 15% → 卖出 1/2 仓位

第三级（激进）：
  涨幅 ≥ 20% → 全部清仓（或保留底仓 10%）

注意：止盈位需结合个股波动率调整
  - 高波动股（20日波动率 > 30%）：止盈位上浮 5%
  - 低波动股（20日波动率 < 15%）：止盈位下调 3%
```

#### 2. 止损卖出

```
触发条件（满足任一）：

硬止损：
  ✅ 亏损 ≥ 8%（绝对止损线，无例外）
  ✅ 跌破 MA20 且放量（成交量 > 5日均量 × 1.2）

软止损（满足两项）：
  ✅ 连续3日收盘价低于 MA10
  ✅ 行业指数跌破 10 日均线
```

#### 3. 趋势破坏卖出

```
触发条件（满足任一）：

  ✅ 股价跌破 MA20 且 3 日内未能收复
  ✅ 所属行业指数（申万/中证）跌破 MA20
  ✅ 大盘（上证指数）跌破 MA60
  ✅ 成交量异常放大（> 5日均量 × 2.0）且股价下跌
```

### 二、卖出规则详解

#### MA20 均线卖出（核心规则）

> **硬约束 H5**：买入/卖出判断必须依赖 20 日均线（MA20），不得仅凭基本面得分直接给出操作建议。

```
MA20 卖出判断：

  股价 > MA20 → 持有（趋势向上）
  股价 = MA20 ± 1% → 观察（警惕变盘）
  股价 < MA20 → 卖出（趋势破坏）
  股价 < MA20 且放量 → 立即卖出（趋势确认破坏）

特殊情况：
  - 震荡行情（股价围绕 MA20 波动）：
    放宽到 ± 3% 区间，配合成交量判断
  - 急涨行情（连续涨停）：
    不使用 MA20，改用收盘价回撤 10% 作为卖出信号
```

#### 分批卖出策略

```
推荐的分批卖出节奏：

  第一目标位（10%）：卖出 30%
  第二目标位（15%）：卖出 30%
  第三目标位（20%）：卖出 30%
  底仓（10%）：跟随 MA20 动态止盈

若股价未达目标位就跌破 MA20：
  → 立即清仓，不等待目标位
```

### 三、动态卖点调整

#### 基于行业周期的卖点调整

| 行业 | 止盈调整 | 止损调整 | 说明 |
|------|----------|----------|------|
| 金融（银行/保险） | 上调 5% | 下调 2% | 波动小，需更大涨幅 |
| 科技/新能源 | 下调 5% | 上调 2% | 波动大，及时止盈 |
| 周期（钢铁/有色） | 按周期调整 | 不变 | 顺周期行业看商品价格 |
| 消费（白酒/家电） | 不变 | 不变 | 稳定行业 |

#### 基于持仓时间的卖点调整

```
持仓时间 < 5 天：
  → 使用标准卖点（激进型）

持仓时间 5-20 天：
  → 止盈位不变，止损位上调到 5%（保护利润）

持仓时间 > 20 天：
  → 止盈位上浮 3%（让利润奔跑）
  → 止损位跟随 MA10（从 MA20 上移）
```

## 执行步骤

```
Step 1: 接收 portfolio-construction 输出的持仓方案

Step 2: 逐股票检查卖出信号
  ├─ 计算当前涨跌幅
  ├─ 检查 MA20 位置（股价 vs MA20）
  ├─ 检查成交量（是否放量）
  ├─ 检查行业趋势（行业指数 vs MA20）
  └─ 检查大盘趋势（上证指数 vs MA60）

Step 3: 计算动态卖点
  ├─ 获取行业波动率 → 调整止盈止损位
  ├─ 获取持仓时间 → 调整止损策略
  └─ 应用分批卖出策略

Step 4: 生成卖点计划
  ├─ 写入目标价（3级止盈）
  ├─ 写入止损价（绝对止损 + MA20 止损）
  └─ 标记当前卖出信号状态

Step 5: 输出卖点计划 → 传递给回测校验环节
```

## 风控检查清单

| # | 检查项 | 规则 | 不通过处理 |
|---|--------|------|-----------|
| S1 | MA20 跌破 | 必须检查 MA20 位置 | 缺少 MA20 数据则暂停该股票卖出判断 |
| S2 | 绝对止损 | 亏损 ≥ 8% 必须止损 | 无例外，立即触发卖出 |
| S3 | 止盈分批 | 禁止一次性全仓止盈 | 强制分批，至少分 3 次 |
| S4 | 行业联动 | 单行业 > 50% 触发行业止损 | 削减该行业所有持仓 |
| S5 | 流动性检查 | 日均成交额 < 5000万 放宽卖出 | 可接受滑点 0.5% |
| S6 | 市场择时 | 大盘跌破 MA60 强制减仓 | 所有持仓减至 20% 以下 |

---

## 注意事项

1. **卖点比买点更重要**：买入时可以分批建仓，但卖出时必须果断止损。
2. **禁止情绪化交易**：所有卖出操作必须有触发理由（止盈/止损/趋势破坏），禁止"感觉要跌"就卖。
3. **硬约束 H5**：MA20 是卖出判断的核心，跌破 MA20 必须减仓，无论基本面多好。
4. **硬约束 H6**：所有卖出操作必须记录委托时间、价格、操作理由，供回测复盘。
5. **盘中监控**：卖点计划生成后，需每日盘中检查是否触发卖出信号，触发后立即执行。
6. **与组合构建协同**：若同一行业多只股票同时触发卖出，需评估行业性风险，考虑集体减仓。
