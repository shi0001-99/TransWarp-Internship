### 共识 vs 争议 速查

**共识5条：**
1. 单一指标必失效，组合+过滤
2. 仓位决定生死，总敞口≤30%
3. 买卖逻辑必须同源
4. 预测≠交易，RL端到端更优
5. A股T+1/涨跌停/北向T+0特权导致传统技术失真

**争议6条：**
技术分析有效？凯利用否？网格圣杯？量化占比？打板可持续？AI取代人？ → 全部在01报告有数据佐证（打板成功率42-44%，20cm炸板62%，SAC提升7.6%）

### 操盘手最关心：6场景×技术失灵速查

- **中盘蓝筹：** MA需叠加期货偏度>1.5，否则假突破67%
- **白马红利：** 筹码+风险平价优于凯利
- **打板：** 由板上确认→买点前置（-5%低吸），单股<10%
- **20cm：** 3x ATR止损，单股<5%，首板炸板率62%教育
- **ETF震荡：** 网格最佳但需底仓70%+网格30%，否则牛市卖飞
- **日内：** 午后14:00-15:00胜率最高，早盘RSI无效

详情见 03 报告大矩阵表格。
