## 系统简介

本系统是一个**网页版A股量化选股工具**，能够自动爬取股票行情数据，基于多维度评分模型选出最具潜力的Top 10股票。

### 核心流程

```
启动 → 爬取股票池列表 → 批量获取实时行情 → 获取历史K线 → 多维度评分 → 排序选出Top10 → Web展示
```

### 设计理念

- **多维度评估**：不只看单一指标，综合均线趋势、成交量、价格位置、换手率、估值、涨跌6大维度
- **每日自动运行**：配置定时任务后，每个交易日9:35自动运行选股
- **可视化界面**：现代化Web界面，支持详情查看、数据导出
- **备用数据源**：主API失败时自动切换到模拟数据，确保系统稳定

## 评分算法详解

### 评分维度与权重

系统采用6维度加权评分模型，满分100分：

| 维度 | 权重 | 评分逻辑 |
|:---|:---:|:---|
| **均线趋势** | 30分 | 均线排列(15分) + MA5/10/20/60斜率(各3.75分) |
| **成交量** | 20分 | 量比1.0-2.0得80分(温和放量)，>2.0得70分，<0.5得30分 |
| **价格位置** | 15分 | 30%-70%中间位置得85分，10%-30%低位得75分 |
| **换手率** | 15分 | 1%-5%得90分(活跃适中)，5%-10%得60分，>10%得40分 |
| **估值** | 10分 | PE 0-20得90分(低估)，20-40得75分，40-80得55分 |
| **当日涨跌** | 10分 | 0-3%得85分(温和上涨)，3-7%得75分，-3%-0%得65分 |

### 评级标准

| 综合得分 | 评级 | 建议 |
|:---:|:---|:---|
| ≥80分 | ⭐⭐⭐⭐⭐ 优秀 | — |
| ≥70分 | ⭐⭐⭐⭐ 良好 | — |
| ≥60分 | ⭐⭐⭐ 中性 | — |
| ≥50分 | ⭐⭐ 偏弱 | — |
| <50分 | ⭐ 较差 | — |

### 投资建议逻辑

| 条件 | 建议 |
|:---|:---|
| 分数≥75 且 多头排列 | ✅ 积极建仓：技术面优秀，均线多头排列，可考虑买入 |
| 分数≥65 | ⚠️ 谨慎关注：技术面良好，可逢低布局 |
| 分数≥55 | 🔍 观察为主：技术面中性，等待更好时机 |
| 分数≥45 | ⚠️ 谨慎：技术面偏弱，建议观望 |
| 分数<45 | ⛔ 回避：技术面较差，不建议参与 |

### 均线排列判断

| 排列类型 | 条件 | 得分 |
|:---|:---|:---:|
| 多头排列 | MA5 > MA10 > MA20 > MA60 | 100 |
| 半多头 | MA5 > MA10 > MA20 | 75 |
| 中性 | 其他情况 | 50 |
| 空头排列 | MA5 < MA10 < MA20 < MA60 | 0 |

## 定时任务配置

### 启动自动任务

在Web界面点击「⏰ 启动定时任务」按钮，系统将在每个工作日（周一至周五）的 **09:35** 自动运行选股。

### 修改定时时间

编辑 `app.py` 中的定时任务配置：

```python
scheduler.add_job(
    run_screening_async,
    'cron',
    day_of_week='mon-fri',    # 周一到周五
    hour=9,                   # 小时（24小时制）
    minute=35,                # 分钟
    id='daily_screening',
    replace_existing=True,
)
```

### 自定义定时规则

APScheduler支持灵活的cron表达式：

| 需求 | 配置示例 |
|:---|:---|
| 每个交易日9:35 | `day_of_week='mon-fri', hour=9, minute=35` |
| 每天早上9点 | `day_of_week='mon-sun', hour=9, minute=0` |
| 每周一早上10点 | `day_of_week='mon', hour=10, minute=0` |
| 每月1号早上8点 | `day='1', hour=8, minute=0` |

## 自定义配置

### 修改股票池

编辑 `data_fetcher.py` 中的 `hot_stocks` 列表：

```python
hot_stocks = [
```

2. 确定市场（上海 `sh` 或深圳 `sz`）
3. 确定行业分类
4. 添加到 `hot_stocks` 列表

### 修改评分权重

编辑 `screener.py` 中的 `_calculate_score` 方法，调整各维度权重：

```python
# 修改元组中的第三个值即为权重
scores.append(("均线趋势", ma_score, 30))   # 30分
scores.append(("成交量", vol_score, 20))    # 20分
scores.append(("价格位置", price_score, 15)) # 15分
scores.append(("换手率", turnover_score, 15)) # 15分
scores.append(("估值", val_score, 10))      # 10分
scores.append(("当日涨跌", change_score, 10)) # 10分

# 注意：所有权重之和应为100
```

调用 `run_screening` 方法时传入 `top_n` 参数：

```python
# screener.py 中的 run_screening 方法
results = screener.run_screening(top_n=10)  # 改为需要的数量
```

### 修改最低分数门槛

```python
results = screener.run_screening(top_n=10, min_score=40.0)
#                                    ↑        ↑
#                                  数量      最低分数
```

## 常见问题

### Q1：启动后无法访问 http://127.0.0.1:5000

**可能原因及解决方案：**

1. **端口被占用**
   ```bash
   # Windows: 查看端口占用
   netstat -ano | findstr :5000
   # 结束占用进程
   taskkill /PID <进程ID> /F
   ```

2. **防火墙拦截**
   - 临时关闭防火墙测试
   - 或添加Python到防火墙例外

3. **多个Python环境**
   - 确认 `pip` 和 `python` 使用同一环境
   ```bash
   python -c "import sys; print(sys.executable)"
   pip show flask
   ```

### Q2：选股结果为空

**可能原因及解决方案：**

1. **非交易时间**：非交易日或非交易时段（9:30-15:00）行情数据可能为0
2. **网络问题**：检查网络连接，确保能访问腾讯/东方财富API
3. **API变更**：数据源API可能已更新，需修改解析逻辑

### Q3：K线数据获取失败

系统会自动使用**模拟数据**作为备用。如果持续获取不到真实数据：

1. 检查网络连接
2. 查看 `data_fetcher.py` 中的 `fetch_kline_history` 方法
3. 可能需要更新API地址

### Q4：定时任务未触发

1. 确认已点击「启动定时任务」按钮
2. 确认当前时间为工作日9:35之后
3. 重启服务器后需要重新启动定时任务

### Q5：Python包安装失败

```bash
# 升级pip
python -m pip install --upgrade pip

# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 逐个安装
pip install flask
pip install requests
pip install pandas
pip install numpy
pip install apscheduler
```

### Q6：浏览器打开页面但无数据

1. 先点击「开始选股」按钮运行分析
2. 等待进度完成后刷新页面
3. 打开浏览器开发者工具（F12）查看Console和Network

### Q7：如何在生产环境部署

