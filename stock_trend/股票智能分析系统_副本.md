# 📈 A股智能分析与预测系统

> **版本**: v2.0  
> **数据来源**: 新浪财经 / 东方财富 (实时数据)  
> **技术栈**: Python + Flask + ECharts + NumPy + Pandas  
> **适用范围**: 全部A股（沪/深/创业板/科创板/北交所）

---

## 🌟 系统概览

本系统是一个基于多因子模型的A股智能分析与预测平台，整合了**技术分析**、**基本面分析**、**消息面分析**、**形态识别**四大维度，通过蒙特卡洛模拟和历史形态匹配，为投资者提供短期趋势预测和买卖信号建议。

### 核心功能

| 功能模块 | 说明 |
|---------|------|
| 🔍 股票搜索 | 支持全市场股票搜索和直接代码输入 |
| 📊 技术指标 | 13种主流技术指标实时计算 |
| 🎨 形态识别 | 20+种K线形态和技术形态自动识别 |
| 📰 消息分析 | 实时新闻获取+政策影响匹配 |
| 📈 走势预测 | 多周期预测+蒙特卡洛模拟 |
| ⚡ 买卖信号 | 多因子共振买卖点生成 |

## 📊 一、技术面分析 (13种指标)

### 1.1 趋势跟踪指标

| 指标 | 说明 | 计算公式/规则 |
|------|------|--------------|
| **MA均线** | 5/10/20/60日移动平均 | `MA = Σ(Close) / N` |
| **MACD** | 趋势动量指标 | DIF=EMA(12)-EMA(26), DEA=EMA(DIF,9) |
| **DMI** | 方向指标 | +DI/-DI, ADX趋势强度 |
| **SAR** | 抛物线止损 | 动态止损位，判断趋势方向 |

### 1.2 超买超卖指标

| 指标 | 说明 | 计算规则 |
|------|------|---------|
| **RSI** | 相对强弱指数 | RSI=100-100/(1+RS)，超买>70，超卖<30 |
| **KDJ** | 随机指标 | K/D/J值，金叉死叉信号 |
| **CCI** | 顺势指标 | CCI=(TP-MA)/(0.015×MD)，超买>100 |
| **WR** | 威廉指标 | WR=(H_max-C)/(H_max-L_min)×100 |
| **PSY** | 心理线 | PSY=N_up/N_total×100，超买>75 |

### 1.3 波动与量能指标

| 指标 | 说明 | 计算规则 |
|------|------|---------|
| **BOLL** | 布林带 | 中轨MA20，上下轨±2倍标准差 |
| **ATR** | 平均真实波幅 | TR=max(H-L,|H-C_prev|,|L-C_prev|) |
| **OBV** | 能量潮 | 上涨+成交量，下跌-成交量 |
| **BIAS** | 乖离率 | BIAS=(C-MA)/MA×100% |
| **量比** | 成交量比率 | 当日前5日均量 |

### 信号示例
```
✅ MA5 > MA10，短期均线多头
✅ MACD红柱，多头动能
✅ CCI超买(129)，回调风险
✅ +DI > -DI，多头占优
✅ OBV在均线上方，资金流入
✅ SAR多头趋势，止损位下方
⚠️ WR超买(8)，回调风险
⚠️ 价格接近布林上轨，超买
```

#### 反转形态
| 形态 | 看涨/看跌 | 特征 |
|------|----------|------|
| 双底 (Double Bottom) | 🟢 看涨 | 两个相似低点，突破颈线 |

| 头肩底 (Inverse H&S) | 🟢 强烈看涨 | 左肩-头-右肩，突破颈线 |
| 头肩顶 (Head & Shoulders) | 🔴 强烈看跌 | 左肩-头-右肩，跌破颈线 |
| V型反转 | 🟢🔴 反转 | 快速下跌/上涨后快速反弹/回调 |
| 岛型反转 | 🟢🔴 反转 | 跳空后快速拉回/回落 |

#### 持续形态
| 形态 | 说明 |
|------|------|
| 上升三角形 | 高点平，低点上移，看涨 |
| 下降三角形 | 高点下移，低点平，看跌 |
| 对称三角形 | 高低点收敛，等待突破 |
| 上升/下降旗形 | 短暂回调/反弹蓄势 |

### 2.3 突破与量价形态

#### 突破形态
- **放量突破压力** - 量比>1.5，有效突破
- **缩量突破** - 量能不足，风险提示
- **横盘突破** - 窄幅整理后突破

#### 量价形态
- **量价齐升** - 健康上涨
- **量价顶背离** - 上涨动能衰竭
- **量价底背离** - 下跌动能衰竭
- **缩量回调** - 上涨后蓄势
- **天量/地量** - 极端量能，变盘信号

## 💰 四、基本面分析

### 4.1 估值指标
| 指标 | 说明 | 参考标准 |
|------|------|---------|
| PE (市盈率) | 股价/每股收益 | 0-30合理，>50高估 |
| PB (市净率) | 股价/每股净资产 | <5较好 |
| PS (市销率) | 股价/每股营业收入 | <3较好 |

### 4.2 盈利能力
| 指标 | 说明 | 参考标准 |
|------|------|---------|
| ROE (净资产收益率) | 净利润/净资产 | >15%优秀 |
| ROA (总资产收益率) | 净利润/总资产 | >5%良好 |
| 毛利率 | (营收-成本)/营收 | >40%高毛利 |

### 4.3 成长能力
| 指标 | 说明 | 参考标准 |
|------|------|---------|
| 营收增长率 | (本期-上期)/上期 | >20%高成长 |
| 净利润增长率 | 同上 | >20%高成长 |

### 评分标准
```
基本面评分 = 估值得分 × 30%
           + 盈利能力得分 × 35%
           + 成长能力得分 × 25%
           + 股息分红得分 × 10%
```

## 🎯 五、预测引擎

### 5.1 多周期预测
| 预测周期 | 说明 |
|---------|------|
| 5天 | 短期趋势预测 |
| 10天 | 中短期预测 |
| 20天 | 中期预测 |

### 5.2 预测方法

#### 蒙特卡洛模拟 (GARCH模型)
```
dS/S = μ·dt + σ·dW

其中:
μ = 预期收益率（基于多因子模型）
σ = 波动率（GARCH(1,1)模型估计）
W = 标准维纳过程
```

#### 历史形态匹配 (KNN)
- 在250天历史中搜索与当前最相似的K个价格片段
- 使用这些片段之后的实际走势预测未来
- 距离加权 + 一致性统计

#### 市场状态自适应
| 市场状态 | 识别条件 | 预测策略 |
|---------|---------|---------|
| 趋势上涨 | MA多头排列 | 趋势跟踪 |
| 趋势下跌 | MA空头排列 | 趋势跟踪 |
| 震荡 | 价格围绕MA波动 | 均值回归 |
| 突破 | 波动收窄后放量 | 突破跟踪 |

## ⚠️ 风险提示

> **重要**: 本系统仅供学习研究使用，不构成任何投资建议。

1. **预测局限性**: 基于历史数据的预测不能保证未来走势
2. **市场风险**: 股票市场存在系统性风险，无法完全预测
3. **数据延迟**: 实时数据可能有15分钟以上的延迟
4. **模型假设**: 预测模型基于有效市场假设，现实可能偏离
5. **技术局限**: 技术指标存在滞后性，需结合基本面综合判断
