# TransAlpha-Scorer 项目说明文档

## 一、项目概述

### 1.1 项目背景

本项目是 TransAlpha 小组的**个股多维度融合打分系统**，旨在实现从股票代码输入到综合Alpha得分输出的全自动化计算流程。系统严格按照小组制定的打分细则进行计算，确保打分结果的客观性和一致性。

### 1.2 核心功能

- **自动数据采集**：从多个数据源获取股票行情、财务、行业、宏观等数据
- **价值基本面打分**：PE分位、PB分位、ROE、盈利质量、资产负债率等指标打分
- **趋势动量打分**：20日涨跌幅、60日动量、资金流入周期等指标打分
- **四大维度打分**：宏观、资金、事件消息维度独立打分
- **综合Alpha总分计算**：基于加权权重自动计算综合得分
- **黑名单过滤**：自动过滤ST、亏损、追高、高估值等风险标的
- **风控预警**：追高预警、高估值预警、行业集中提示

### 1.3 项目目标

实现**输入股票代码 → 自动计算所有打分 → 输出中间分数和最终分数**的完整流程。

## 三、打分流程

### 3.1 完整流程图

```
输入股票代码
    ↓
黑名单过滤检查
    ├── 通过 → 继续下一步
    └── 不通过 → 输出黑名单原因，终止流程
    ↓
数据采集（行情、财务、行业、宏观、资金、事件）
    ↓
价值基本面打分
    ├── PE分位打分
    ├── PB分位打分
    ├── ROE打分（含连续年限加分）
    ├── 现金流打分
    ├── 增长稳定性打分
    ├── 盈利质量打分（ROE*0.4 + 现金流*0.3 + 增长稳定性*0.3）
    ├── 资产负债率打分
    └── 价值基本面总分（加权平均）
    ↓
趋势动量打分
    ├── 追高检查（近3日涨幅≥15%→趋势0分）
    ├── 20日涨跌幅打分
    ├── 60日动量打分
    ├── 资金流入周期打分
    └── 趋势动量总分（加权平均）
    ↓
四大维度独立打分
    ├── 宏观维度打分
    ├── 资金维度打分
    └── 事件消息维度打分
    ↓
综合Alpha总分计算（加权求和）
    ├── 价值基本面 × 40%
    ├── 趋势动量 × 25%
    ├── 宏观环境 × 15%
    ├── 资金流向 × 10%
    └── 事件消息 × 10%
    ↓
评级判定
    ├── ≥9分 → 优秀
    ├── 8-9分 → 良好
    ├── 6-8分 → 中等（进入候选池）
    ├── 4-6分 → 观察
    └── <4分 → 淘汰
    ↓
风控预警检查
    ├── 追高预警
    ├── 高估值预警
    └── 输出最终结果
```

## 五、使用方法

### 5.1 安装依赖

```bash
cd TransAlpha-Scorer
pip install -e .
```

### 5.2 命令行调用

```bash
# 基本用法：输入股票代码
transalpha-score 000001.SZ

# 保存结果到文件
transalpha-score 000001.SZ -o

# 输出JSON格式
transalpha-score 000001.SZ -j

# 显示当前打分配置
transalpha-score --config
```

### 5.3 Python API调用

```python
from transalpha import CompositeScorer

scorer = CompositeScorer()
result = scorer.calculate_composite_score("000001.SZ")

print(f"综合Alpha得分: {result['overall_score']}")
print(f"评级: {result['rating']}")
print(f"价值基本面得分: {result['value_fundamental']['value_fundamental_score']}")
print(f"趋势动量得分: {result['trend_momentum']['trend_momentum_score']}")
```

## 八、注意事项

1. **数据源依赖**：当前 `data_fetcher.py` 为占位实现，实际使用时需接入真实数据源（东方财富Choice、Wind等）
2. **行业数据**：行业分位数计算需要完整的行业股票列表数据
3. **实时性**：宏观数据和事件数据可能存在滞后，需注意数据更新频率
4. **人工复核**：系统打分结果仅供参考，最终投资决策需经投委会投票确认
