# TransAlpha-Scorer 使用指南

## 一、环境准备

```bash
cd TransAlpha-Scorer
pip install -e .
```

如果提示依赖冲突，无视即可。

---

## 二、数据输入方式

### 方式1：直接命令行输入股票代码（支持多个）

```bash
# 单只股票
python -m transalpha.cli 000001.SZ

# 多只股票同时评分（空格分隔）
python -m transalpha.cli 000001.SZ 600519.SH 002156.SZ
```

### 方式2：批量模式（逗号分隔）

```bash
python -m transalpha.cli -b 000001.SZ,002156.SZ,002602.SZ
```

### 方式3：保存结果到JSON文件

```bash
python -m transalpha.cli -b 000001.SZ,600519.SH -o
# 结果保存到 output/ 目录
```

### 方式4：指定总资金计算持仓建议

```bash
python -m transalpha.cli 000001.SZ 002156.SZ --capital 500000 --max-positions 5
# --capital 总资金（默认100万）
# --max-positions 最大持仓数（默认5只）
```

### 方式5：JSON格式输出

```bash
python -m transalpha.cli 000001.SZ -j
```

### 方式6：查看当前打分配置

```bash
python -m transalpha.cli --config
```

### 股票代码格式说明

以下格式都支持：

| 输入 | 说明 |
|------|------|
| `000001.SZ` | 深交所标准格式 |
| `600519.SH` | 上交所标准格式 |
| `000001` | 纯数字（自动识别） |

### 黑名单情况

如果股票被黑名单过滤，输出会简化并标明原因：

```
============================================================
股票代码: 688146.SH
股票名称: 中船特气
所属行业: 半导体
------------------------------------------------------------
【黑名单剔除】
  - 近3日涨幅17.0%≥15%
============================================================
```

**黑名单触发条件**：
- ST/ST* 标识
- 连续2年亏损
- 单日换手率 > 20%
- PE行业分位 > 90%
- 近3日涨幅 ≥ 15%（追高）

### 各评级对应仓位

| 综合评分 | 评级 | 建议仓位 |
|:--------:|:----:|:--------:|
| ≥ 9 | 优秀 | 25% |
| ≥ 8 | 良好 | 20% |
| ≥ 6 | 中等 | 15% |
| ≥ 4 | 观察 | 8% |
| < 4 | 淘汰 | 0% |

## 四、Python API调用

```python
from transalpha import CompositeScorer, PositionSizer

# 评分
scorer = CompositeScorer()
result = scorer.calculate_composite_score("000001.SZ")
print(f"综合得分: {result['overall_score']}")
print(f"价值基本面: {result['value_fundamental']['value_fundamental_score']}")
print(f"趋势动量: {result['trend_momentum']['trend_momentum_score']}")

# 持仓建议
sizer = PositionSizer(total_capital=1000000)
pos = sizer.suggest_single_position(result)
print(f"建议仓位: {pos['suggested_ratio']}%")
```

## 五、权重配置

可在 `src/transalpha/config.py` 中调整：

| 维度 | 默认权重 |
|------|:--------:|
| 价值基本面 | 40% |
| 趋势动量 | 25% |
| 宏观环境 | 15% |
| 资金流向 | 10% |
| 事件消息 | 10% |

## 六、注意事项

1. **首次运行需要联网**：从东方财富/baostock 拉取实时数据
2. **运行时间**：每只股票约需 5-15 秒（取决于网络）
3. **宏观/资金/事件**：这三个维度目前返回默认分（5分），如需接入真实数据需扩展 `data_fetcher.py`
4. **行业分位数**：PE/PB行业分位暂为默认5分，需接入行业全量数据后才能准确计算
5. **结果仅供参考**：系统打分结果仅供内部参考，最终投资决策需经投委会确认
