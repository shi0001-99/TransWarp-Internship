# 股票凯利分析器 - 使用说明

## 一、项目简介

股票凯利分析器是一个基于Python的股票分析Web应用，通过多维度评分体系和凯利公式，为用户提供智能化的投资决策支持。

### 核心功能

- **实时价格获取**：通过akshare分钟K线接口获取盘中实时价格（延迟约3秒），非日K线收盘价
- **五维度评分体系**：价值基本面(25%)、趋势动量(45%)、宏观环境(5%)、资金流向(15%)、事件消息(10%)
- **凯利公式计算**：根据评分转换为胜率，利用凯利公式计算最优投资比例
- **双数据源**：baostock（日K线，用于技术指标）+ akshare分钟K线（实时价格）
- **宏观环境分析**：行业板块指数、大盘指数涨跌分析
- **事件新闻分析**：个股及行业新闻情感分析
- **Web界面**：现代化响应式Web界面，支持局域网访问

## 三、快速开始

### 3.1 安装依赖

打开命令行（CMD或PowerShell），进入项目目录，执行：

```bash
cd 股票凯利分析器
pip install -r requirements.txt
```

若baostock未自动安装，可手动执行：
```bash
pip install baostock requests flask-cors
```

### 3.2 启动服务器

**方式一：双击启动（推荐）**
```
双击 "启动服务器.bat"
```

**方式二：命令行启动**
```bash
python start_server.py
```

**方式三：后台守护模式（7×24小时运行）**
```bash
python server_daemon.py
```

启动成功后，浏览器访问：**http://127.0.0.1:5000**

### 3.3 停止服务器

```
双击 "停止服务器.bat"
```

或命令行执行：
```bash
python stop_server.py
```

## 四、使用指南

### 4.1 基本操作流程

1. **启动服务器**：双击 `启动服务器.bat`
2. **打开网页**：浏览器访问 `http://127.0.0.1:5000`
3. **输入股票代码**：在搜索框输入6位股票代码（如 300753、600519、002422）
4. **设置投资金额**：输入总资金金额（默认100万元）
5. **点击分析**：点击"开始分析"按钮，系统将获取数据并进行评分
6. **查看结果**：查看综合评分、凯利公式分析和投资建议

### 4.2 实时价格说明

本系统采用**双数据源合并策略**，确保价格实时性：

| 数据类型 | 数据源 | 用途 | 缓存时间 |
|---------|--------|------|---------|
| 日K线历史数据 | baostock / akshare | 计算5日/20日收益率、波动率、52周高低等技术指标 | 10分钟 |
| 实时分钟价格 | akshare 分钟K线（新浪源） | 当前价格、实时涨跌幅、今日累计成交量 | 60秒 |

**工作原理**：
- **盘中**（9:30-15:00）：显示实时价格，涨跌幅基于昨收价计算，成交量 为今日累计
- **收盘后**：日K线已更新当日数据，实时价格与收盘价一致
- **非交易日**：显示最近一个交易日的收盘数据

界面上价格旁边会显示绿色"实时"标签，表示当前价格 为盘中实时数据。

### 4.3 股票代码格式

| 市场 | 代码前缀 | 示例 |
|------|---------|------|
| 上海主板 | 600/601/603/605 | 600519（贵州茅台） |
| 深圳主板 | 000/001/002 | 000001（平安银行） |

### 4.4 评分体系说明

| 评分等级 | 分数范围 | 含义 | 建议 |
|---------|---------|------|------|
| ⭐⭐⭐⭐⭐ 优秀 | 8.5-10分 | 多维度表现优秀 | 可考虑建仓 |
| ⭐⭐⭐⭐ 良好 | 7.0-8.5分 | 整体情况良好 | 可适当关注 |
| ⭐⭐⭐ 中等 | 5.0-7.0分 | 中性偏多 | 观望为主 |
| ⭐⭐ 观察 | 3.0-5.0分 | 存在风险 | 谨慎操作 |
| ⭐ 淘汰 | 0-3.0分 | 风险较大 | 建议回避 |

### 4.5 凯利公式说明

**公式**：`f = (bp - q) / b`

- `f`：建议投资比例
- `b`：盈亏比（平均盈利/平均亏损）
- `p`：胜率（由评分转换得出）
- `q = 1 - p`：败率

**评分转胜率对照**：
| 综合评分 | 胜率 |
|---------|------|
| 10分 | 75% |
| 7分 | 57% |
| 5分 | 45% |
| 3分 | 37% |
| 0分 | 35% |

## 五、高级功能

### 5.1 开机自启动

如需电脑重启后自动启动服务器：

1. **双击 `install_autostart.bat`**（需管理员权限）
2. 脚本将在Windows启动目录创建快捷方式
3. 下次开机时服务器将自动启动

**取消自启动**：
```
删除以下文件之一即可：
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\StockAnalyzer.vbs
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\StockAnalyzer.bat
```

### 5.2 局域网访问

如需让同一局域网内其他设备（手机、其他电脑）访问：

1. **双击 `设置防火墙.bat`**（需管理员权限）
2. 获取本机局域网IP（打开CMD执行 `ipconfig`，找到IPv4地址）
3. 其他设备访问：`http://<本机IP>:5000`

### 5.3 服务器守护模式

守护模式会每30秒检查一次服务器健康状态，若服务器无响应则自动重启：

```bash
python server_daemon.py
```

### 5.4 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/analyze` | POST | 分析股票，参数：`{code: "300753", capital: 1000000}` |
| `/api/health` | GET | 服务器健康检查 |
| `/api/status` | GET | 服务器运行状态 |
| `/api/clear_cache` | POST | 清除所有缓存数据 |

## 七、常见问题

### Q1：启动后网页打不开？
- 检查服务器是否启动成功（命令行窗口是否还在运行）
- 检查端口5000是否被占用（可运行 `netstat -ano | findstr :5000`）
- 尝试以管理员身份运行启动脚本

### Q2：分析一直显示"正在分析中"？
- 首次分析某些股票可能需要30-60秒，请耐心等待
- 实时价格获取需额外3-5秒
- 检查网络连接是否正常

### Q3：显示"服务器繁忙"错误？
- 当前有其他分析正在进行中，请等待完成后再试
- 同时只支持一个分析请求（避免数据源冲突）

### Q4：局域网其他设备无法访问？
- 确认已运行 `设置防火墙.bat` 并添加了防火墙规则
- 确认访问地址使用的是本机局域网IP（如 192.168.x.x）

### Q5：实时价格不更新？
- 实时价格缓存60秒，1分钟后再次分析即可获取最新价
- 可访问 `/api/clear_cache` 接口手动清除缓存
- 非交易时段显示的是最近一个交易日的收盘价

### Q6：电脑重启后服务器没启动？
- 确认已运行 `install_autostart.bat`
- 某些杀毒软件可能会阻止开机启动，请添加信任

## 八、注意事项

1. **实时价格**：盘中价格通过分钟K线获取，延迟约3-5秒，非完全逐笔实时
2. **投资风险**：本工具仅为量化分析参考，**不构成投资建议**
3. **网络依赖**：需要联网获取数据，网络异常时自动降级为日K线收盘价
4. **数据缓存**：日K线缓存10分钟，实时价格缓存60秒，避免频繁请求
5. **浏览器兼容**：推荐使用 Chrome、Edge、Firefox 等现代浏览器
