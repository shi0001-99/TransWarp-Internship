## 一、系统概述

本系统是一套面向 A 股市场的智能股票分析工具，核心逻辑为：

```
输入股票 → 行业识别 → 基本面过滤 (行业特定标准) → 多维度打分 (估值/价格/热度) → 凯利公式计算最优仓位 → 输出投资建议
```

### 设计理念

| 模块 | 解决的问题 | 技术方法 |
|------|-----------|---------|
| **行业识别** | 不同行业财务特性差异大 | 关键词+代码前缀自动分类 |
| **基本面过滤** | 垃圾股避雷 | 行业差异化阈值 + 可豁免机制 |
| **多维度打分** | 好股也需好价格 | 估值×价格×热度三维加权 |
| **凯利公式** | 仓位科学管理 | f\* = (bp−q)/b, 半凯利稳健版 |

## 四、行业识别器 (v2.0 新增)

### 4.1 设计背景

不同行业的财务特性差异巨大，使用统一标准会导致：
- **银行股**因 ROE 低（2-3%）和负债率高（90%+）被误判
- **科技股**因估值高（PE 100+）和现金流周期性波动被误判
- **白酒股**因现金流季节性波动被误判

### 4.2 行业识别逻辑

`IndustryClassifier` 类采用三级优先级识别：

```python
classify(code, name, full_code) -> Dict:
    # 优先级 1: 名称关键词匹配 (置信度 95%)
    if name 包含行业关键词:
        return industry
    
    # 优先级 2: 完整代码前缀匹配 (置信度 60%)
    if full_code 以行业前缀开头:
        return industry
    
    # 优先级 3: 代码前缀匹配 (置信度 50%)
    if code 以行业前缀开头:
        return industry
    
    # 默认: 返回 "通用" 行业
    return "通用"
```

### 4.3 支持的行业

### 5.1 分行业阈值配置

#### 各行业阈值对比

|------|---------|----------|----------|----------|---------|------------|--------|
| 🏦 银行 | 2% | 95% | — (跳过) | — (跳过) | — (跳过) | ✅ | 30 |
| 📋 保险 | 3% | 90% | — (跳过) | — (跳过) | — (跳过) | ✅ | 35 |
| 🍶 白酒 | 10% | 60% | 40% | 20% | 1.5 | ❌ | 40 |
| 🛒 消费 | 8% | 65% | 15% | 5% | 1.2 | ❌ | 50 |
| 💻 半导体 | -5% | 60% | 0% | — (跳过) | 1.0 | ✅ | 300 |
| 🚀 科技 | -2% | 60% | 5% | — (跳过) | 1.0 | ✅ | 200 |
| 💊 医药 | 3% | 65% | 30% | 5% | 1.2 | ❌ | 80 |
| 📊 通用 | 5% | 70% | 10% | 3% | 0.8 | ❌ | 500 |

> 说明：`— (跳过)` 表示该指标对此行业不适用，设为 `None` 自动跳过检查

### 5.2 过滤规则（9 项行业差异化指标）

任何一项不达标即判定为 **基本面不合格**，系统会列出具体原因：

| # | 指标 | 默认阈值 | 可豁免行业 | 原理 |
|---|------|---------|----------|------|
| 1 | ROE | ≥ 5% | 银行/半导体(-5%) | 盈利能力底线，行业差异大 |
| 2 | 营收同比 | ≥ −20% | — | 行业下行期允许短期下滑但不能崩盘 |
| 3 | 净利润同比 | ≥ −30% | — | 盈利质量比营收更重要 |
| 4 | 销售毛利率 | ≥ 10% | 银行/保险(跳过) | 产品/服务必须有基本定价权 |
| 5 | 销售净利率 | ≥ 3% | 银行/保险/科技/半导体(跳过) | 扣除费用后必须有正回报 |
| 6 | 资产负债率 | ≤ 70% | 银行(95%)/保险(90%) | 控制财务杠杆，行业差异大 |
| 7 | 流动比率 | ≥ 0.8 | 银行/保险(跳过) | 短期偿债能力底线 |
| 8 | PE 范围 | 0.1 ~ 500 | 各行业有专属上限 | 排除亏损股和估值极端值 |
| 9 | 经营现金流 | > 0 | 银行/半导体/科技(允许) | 排除"纸面盈利"公司 |

## 六、多维度打分引擎

### 6.1 评分体系

满分 **100 分**，三大维度加权：

```
综合得分 = 估值分 × 35% + 价格分 × 35% + 热度分 × 30%
```

### 6.2 估值分（0-100）

评估「贵不贵」，基于 PE 和 PB 分档评分：

**PE 评分表：**

| PE 区间 | 得分 | 含义 |
|--------|------|------|
| < 15 | 90 | 估值较低，安全边际高 |
| 15-25 | 75 | 估值合理 |
| 25-40 | 60 | 估值中等 |
| 40-80 | 40 | 估值偏高 |
| > 80 | 20 | 估值昂贵 |

**PB 评分表：**

| PB 区间 | 得分 | 含义 |
|--------|------|------|
| < 1.5 | 90 | 破净或接近破净，价值洼地 |
| 1.5-3 | 75 | 估值合理 |
| 3-6 | 60 | 估值中等 |
| 6-10 | 40 | 估值偏高 |
| > 10 | 20 | 估值昂贵 |

### 6.3 价格分（0-100）

评估「位置好不好」，两个子维度：

**① 价格位置分（逆向思维）**
- 当前价距 60 日最低点越近 → 分数越高
- 公式：`position_score = (1 − position_ratio) × 80 + 20`

**② 趋势分**
- 近 20 日涨跌在 −5% ~ +10% 区间 → 最优 (80 分)
- 回调 −15% ~ −5% → 良好 (70 分，回调是买点)
- 上涨 > 10% → 扣分 (趋势过热)

### 6.4 热度分（0-100）

评估「活不活跃」：

**① 换手率评分：**

| 换手率(%) | 得分 | 解读 |
|----------|------|------|
| 0.5 ~ 5 | 85 | 活跃度适中 |
| 0.2 ~ 0.5 | 65 | 活跃度偏低 |
| 5 ~ 15 | 55 | 活跃度偏高 |
| > 15 | 30 | 过热，小心追高 |
| < 0.2 | 40 | 低迷，无人关注 |

**② 成交量趋势评分：**

| 近5日/前5日量比 | 得分 | 解读 |
|----------------|------|------|
| 0.8 ~ 1.5 | 75 | 量能稳定 |
| 1.5 ~ 2.0 | 60 | 温和放量 |
| > 2.0 | 40 | 突然放量，警惕出货 |
| < 0.5 | 35 | 严重缩量 |

### 6.5 评分等级

| 分数区间 | 等级 | 决策参考 |
|---------|------|---------|
| 80-100 | ⭐⭐⭐⭐⭐ 优秀 | 重点关注 |
| 65-80 | ⭐⭐⭐⭐ 良好 | 可考虑建仓 |
| 50-65 | ⭐⭐⭐ 中性 | 谨慎参与 |
| 35-50 | ⭐⭐ 偏弱 | 观望为主 |
| 0-35 | ⭐ 较差 | 回避 |

## 七、凯利公式引擎

### 7.1 理论基础

凯利公式（Kelly Criterion）由 John Larry Kelly Jr. 于 1956 年提出，用于计算**长期复利最大化**的最优投注比例。

**标准公式：**

```
f* = (b × p − q) / b
```

| 参数 | 含义 | 取值范围 |
|------|------|---------|
| f* | 最优仓位比例 | [0, +∞) |
| b | 盈亏比 = 预期盈利 / 预期亏损 | > 0 |
| p | 获胜概率 | [0, 1] |
| q | 失败概率 = 1 − p | [0, 1] |

### 7.2 股票市场适配

#### 第一步：估算胜率 p

基准胜率 50%，叠加三个调整因子：

```
胜率 p = 50% + 基本面质量加成 + 综合得分加成
```

**基本面质量加成：**

| 指标 | 条件 | 加成 |
|------|------|------|
| ROE | > 15% | +10% |
| ROE | > 8% | +5% |
| 净利润增速 | > 20% | +8% |
| 净利润增速 | > 0% | +4% |
| 净利率 | > 20% | +5% |
| 净利率 | > 10% | +2% |

**综合得分加成：** `(score − 50) / 200`，范围 −25% ~ +25%

**最终胜率范围：** 30% ~ 85%

#### 第二步：估算盈亏比 b

基于历史波动率：

```python
# 计算日收益率标准差 (波动率)
volatility = std(每日收益率)
# 年化波动率
annual_vol = volatility × √252
# 预期盈利 = 年化波动率 × 胜率 × 2
# 预期亏损 = 年化波动率 × (1 − 胜率) × 2
# 盈亏比 = 预期盈利 / 预期亏损
```

#### 第三步：半凯利调整

纯凯利公式偏激进，A 股使用 **半凯利** 策略更稳健：

```
最终仓位 = 凯利计算结果 × 50%
```

#### 第四步：仓位等级

| 凯利系数 | 建议仓位 | 等级 |
|---------|---------|------|
| ≥ 50% | 50-70% | 🔴 高仓位 |
| 30-50% | 30-50% | 🟠 中高仓位 |
| 15-30% | 15-30% | 🟡 中仓位 |
| 0-15% | 0-15% | 🟢 轻仓试探 |
| ≤ 0% | 空仓 | ⚫ 建议观望 |

### 7.3 示例

以贵州茅台（600519）为例：

```
基本面: ROE 10.57%, 净利增速 +1.47%, 净利率 52.22%
  → 基本面质量加成 = 5% + 4% + 5% = 14%
综合得分: 52.2 → 得分加成 = (52.2-50)/200 = 1.1%
→ 胜率 p = 50% + 14% + 1.1% ≈ 65.1%

年化波动率: 23.98%
→ 预期盈利 = 0.2398 × 0.651 × 2 = 0.3114
→ 预期亏损 = 0.2398 × 0.349 × 2 = 0.1674
→ 盈亏比 b = 0.3114 / 0.1674 ≈ 1.87

凯利系数 f = (1.87 × 0.651 − 0.349) / 1.87 = 0.464
半凯利 = 0.464 / 2 = 0.232 → 23.2%

→ 建议: 🟡 中仓位 23.2%
```

### 示例 3：常见问题

**Q: 行业识别不准确？**
A: 可在 `INDUSTRY_MAP` 中添加更精确的关键词，或直接修改代码中识别逻辑。
