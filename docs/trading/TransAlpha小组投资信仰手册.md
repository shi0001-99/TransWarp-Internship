## 一、投资信仰

本手册作为 TransAlpha 量化投资团队（以下简称"团队"）的最高决策基准。所有交易决策、模型参数调整、AI Agent 执行逻辑均不得违背本手册划定的边界。当市场波动、模型信号与信仰冲突时，**以本信仰手册为准，暂停交易并由全体成员重新评估。**

### 1.1 投资定位

| 维度     | 定义                                                                 |
| ------ | ------------------------------------------------------------------ |
| 核心策略   | **超短线交易**，持仓周期严格控制在 **3 个交易日以内**（通常为 T+1 至 T+3），绝不恋战 |
| 覆盖行业   | **全行业覆盖**，重点跟踪：食品饮料、高科技（半导体/AI/机器人）、矿产资源（有色/煤炭）、机械设备、医疗医药、新能源、数字经济等所有热门板块 |
| 选股逻辑   | **资金驱动 + 技术形态 + 短线催化**。不依赖长线基本面，聚焦短期市场情绪、资金流向与技术共振 |
| 决策理念   | **信号为王，纪律为纲**。AI 负责全市场信号扫描与形态识别，人类负责最终确认与风控把关 |

### 1.2 风险承受上限（核心红线）

团队全体成员需严格遵守以下风险上限，任何量化模型与 AI Agent 均无权突破：

| 指标       | 阈值      | 处理机制                                                                          |
| --------- | ------- | ----------------------------------------------------------------------------- |
| 单只个股最大仓位 | **10%** | AI 计算后若超 10%，自动降权至 10% 以下；人类调仓若超 10%，系统拒绝执行并触发风控警报                          |
| 组合最大允许回撤 | **5%**  | 回撤达 3% 触发预警（仓位减半）；回撤达 5% 触发熔断（停止所有买入操作，逐步降低整体仓位至防御状态）                          |
| 单行业最大仓位  | 30%     | 防止过度集中于单一板块，确保至少覆盖 3 个不同行业                                                                    |
| 日最大亏损容忍   | 2%      | 单日亏损超 2%，暂停当日所有交易，复盘原因                                                        |
| **最大持仓天数** | **3 天** | 任何持仓超过 3 个交易日，系统自动标记并强制平仓，防止短线变长线                                            |

### 1.3 交易纪律（短线版）

1. **追强不抄底**：短线交易只做强势股、热点板块龙头，绝对不碰下跌趋势中的反弹。强势股的定义：5日均线向上、成交量放大、板块热度排名前三。
2. **快进快出**：买入后严格设置止盈止损。止盈位通常为 3-5%（短线不贪多），止损位为 -2%（严格止损，亏损不拖）。
3. **不过夜风险**：持仓若在 T+2 收盘前未达预期走势（量能萎缩、跌破支撑），无论盈亏必须减仓或清仓。
4. **板块优先**：选股顺序为 "板块热度 → 龙头个股 → 技术形态"，不在冷门板块里挖"金子"。
5. **信号消失即离场**：买入依据的技术信号一旦破坏（如放量滞涨、跌破当日低点），立即离场，不抱侥幸心理。

### 1.4 AI Agent 行为准则

团队的 AI Agent 必须遵守以下硬性约束：

- **强制暂停节点**：在"选股筛选"、"趋势分析"、"凯利仓位"后必须暂停，等待人类抽查与确认。
- **禁止模拟数据**：当第三方 API 不可用时，AI 必须返回空列表或硬编码备用池，严禁生成"模拟 K 线"或"伪造数据"。
- **仓位硬限制**：凯利公式输出的建议仓位若违反第 1.2 节的风险上限，AI 必须自动截断并标记警告。
- **持仓天数监控**：AI 必须实时监控所有持仓的 T+N 天数，对 T+3 到期持仓自动生成平仓提醒。
- **行业分散**：AI 选股时必须确保候选股覆盖至少 3 个不同申万一级行业，防止单一行业过度集中。
