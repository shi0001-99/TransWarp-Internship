# 子流程：⑧ 风险检查

> **对应流水线环节**：⑧ 风险检查｜安全层
> **前置文档**：`main_auto_workflow.md`、`portfolio-construction_auto_workflow.md`、`review-backtest_auto_workflow.md`、`TransAlpha小组投资信仰手册.md`
> **后置环节**：⓪ 人工审查④ → ⑨ 调仓执行
> **输出目录**：`output/risk-check/risk_report.json`
>
> **设计依据**：`AI量化投资流水线(1).md` ⑧ 风险检查——"核查风险指标：单一行业集中度、个股黑天鹅风险、流动性风险；制定降级规则：高风险标的下调仓位或直接剔除；风险不通过禁止进入实盘/模拟调仓。"

---

## 目标

对 ⑥ 组合构建产出的持仓方案和 ⑦ 回测校验的绩效结果进行**全方位风险核查**，确保组合方案不违反 `TransAlpha小组投资信仰手册.md` 第 1.2 节"风险承受上限（核心红线）"，生成风控检查报告供⓪人工审查④决策（放行或退回）。

> **核心原则**（来自信仰手册）：风控规则校验为**刚性边界**，AI 主导，**禁止人类临时豁免**。风险不通过，禁止进入调仓执行，没有例外。

---

## 输入

| 输入项 | 来源 | 说明 |
| --- | --- | --- |
| 持仓方案 | `output/portfolio-construction/portfolio.json` | 个股仓位、行业分布、凯利仓位 |
| 回测绩效 | `output/backtest/metrics.json` | 收益率、最大回撤、胜率、盈亏比 |
| 交易记录 | `output/backtest/trade_log.csv` | 回测期间的逐笔交易 |
| 信仰手册红线 | `TransAlpha小组投资信仰手册.md` 1.2 节 | 风险承受上限阈值 |

---

## 风险检查清单

### 一、信仰手册核心红线（刚性，一票否决）

> 全部来自 `TransAlpha小组投资信仰手册.md` 第 1.2 节"风险承受上限（核心红线）"。

| # | 检查项 | 阈值 | 不通过处理 | 边界性质 |
| --- | --- | --- | --- | --- |
| R1 | 单只个股最大仓位 | ≤ **10%** | 超限自动降权至 10% 以下 | 刚性，不可豁免 |
| R2 | 组合最大允许回撤 | ≤ **5%** | 回撤达 3% 预警（仓位减半）；达 5% 熔断（停止买入，降仓位至防御状态） | 刚性，不可豁免 |
| R3 | 单行业最大仓位 | ≤ **30%** | 超限行业按得分从低到高剔除 | 刚性，不可豁免 |
| R4 | 日最大亏损容忍 | ≤ **2%** | 单日亏损超 2%，暂停当日所有交易 | 刚性，不可豁免 |
| R5 | 最大持仓天数 | ≤ **3 天** | 超 T+3 系统自动标记强制平仓 | 刚性，不可豁免 |

### 二、组合结构风险检查

| # | 检查项 | 规则 | 不通过处理 |
| --- | --- | --- | --- |
| R6 | 持仓数量 | ≥ 5 只 | 不足则从观察池补入 |
| R7 | 行业分散度 | 覆盖 ≥ 3 个不同申万一级行业 | 不足则补入其他行业标的（信仰手册 1.4 节） |
| R8 | ST/停牌检查 | 不得持有 ST/*ST 或停牌股票 | 立即剔除 |
| R9 | 流动性检查 | 日均成交额 ≥ 5000万 | 不达标直接剔除 |
| R10 | 总仓位上限 | ≤ 80%（保留至少 20% 现金储备） | 等比例缩小 |

### 三、回测绩效风险检查

| # | 检查项 | 达标线 | 不通过处理 |
| --- | --- | --- | --- |
| R11 | 年化收益率 | ≥ 15% | 退回 ⑤ 因子打分，调整因子权重 |
| R12 | 最大回撤 | ≤ 15% | 退回 ⑥ 组合构建，增加分散度 |
| R13 | 胜率 | ≥ 55% | 退回 ⑤ 因子打分，收紧买入条件 |
| R14 | 盈亏比 | ≥ 1.5 | 退回 ⑤ 因子打分，调整止盈止损位 |
| R15 | 行业集中度（回测） | 单行业 ≤ 30% | 退回 ⑥ 组合构建，强制分散 |

### 四、个股黑天鹅风险检查

| # | 检查项 | 规则 | 不通过处理 |
| --- | --- | --- | --- |
| R16 | 估值风险 | PE/PB 偏离行业均值 > 2 倍标准差 | 下调仓位 50% 或剔除 |
| R17 | 解禁风险 | 近 30 日有限售股解禁且规模 > 流通市值 5% | 下调仓位或剔除 |
| R18 | 商誉风险 | 商誉占净资产 > 50% | 下调仓位或剔除 |
| R19 | 情绪风险 | 换手率 > 15%（一家独大，游资打板） | 轻仓试错，仓位 ≤ 5% |

### 五、大盘择时风险检查

```
上证指数状态              仓位调整              处理
──────────────────────────────────────────────────────
> MA20（牛市）            正常仓位（100%）       放行
跌破 MA20 但 > MA60       降至 50% 仓位          预警
跌破 MA60（熊市）          空仓观望（0%）         熔断，全部清仓
```

> 当前版本人工判断，后续开发 `market_timing.py` 模块自动化。

## 执行步骤

```
Step 1: 读取 ⑥ 组合构建输出的持仓方案
  └─ output/portfolio-construction/portfolio.json

Step 2: 读取 ⑦ 回测校验输出的绩效指标
  └─ output/backtest/metrics.json

Step 3: 信仰手册核心红线检查（R1-R5）
  ├─ 逐条检查，记录通过/不通过
  └─ 任一不通过 → 标记为"风控不通过"，生成退回建议

Step 4: 组合结构风险检查（R6-R10）
  ├─ 持仓数量、行业分散度、ST/停牌、流动性、总仓位
  └─ 不通过项记录降级处理方案

Step 5: 回测绩效风险检查（R11-R15）
  ├─ 对照达标线检查收益率/回撤/胜率/盈亏比/集中度
  └─ 不通过项记录退回环节和建议

Step 6: 个股黑天鹅风险检查（R16-R19）
  ├─ 逐股票检查估值/解禁/商誉/情绪风险
  └─ 高风险标的记录降级处理方案

Step 7: 大盘择时风险检查
  ├─ 判断上证指数与 MA20/MA60 的关系
  └─ 触发熔断则标记"全部清仓"

Step 8: 汇总生成风控报告 → output/risk-check/risk_report.json
  ├─ 总体结论：放行 / 退回 / 熔断
  ├─ 不通过项清单 + 退回环节 + 建议处理方案
  └─ 传递给 ⓪ 人工审查④
```

## 注意事项

1. **风控一票否决**（来自 `AI量化投资流水线(1).md`）：风险检查不通过，禁止进入 ⑨ 调仓执行/模拟调仓，没有例外。
2. **信仰手册红线不可豁免**（来自信仰手册 1.4 节）：R1-R5 为核心红线，即使⓪人工审查④中人类要求放行，系统也必须拒绝执行并触发风控警报。
3. **退回机制**：风控不通过时，报告需明确指出退回到哪个环节（⑤ 因子打分 / ⑥ 组合构建）及具体建议。
4. **熔断机制**：大盘跌破 MA60 或组合回撤达 5% 时，触发熔断，全部清仓观望。
5. **持仓天数监控**（来自信仰手册 1.4 节）：AI 必须实时监控所有持仓的 T+N 天数，对 T+3 到期持仓自动生成平仓提醒。
6. **当前实现状态**：`src/risk/checker.py` 待建，当前由 `review-backtest_auto_workflow.md` 中的风险检查清单临时承接。后续需独立模块化。
