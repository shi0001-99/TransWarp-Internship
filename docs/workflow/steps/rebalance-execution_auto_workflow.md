## 目标

对 ⓪人工审查④放行的持仓方案进行**执行前二次核对**，生成委托指令并执行调仓，同时启动**实时监控**（含卖点信号检测、七大预警规则、持仓天数监控），确保所有操作可追溯，禁止无依据临时交易。

> **核心原则**（来自信仰手册 1.3 节）：
> - 快进快出：买入后严格设置止盈止损，止盈 3-5%，止损 -2%
> - 不过夜风险：T+2 收盘前未达预期走势，无论盈亏必须减仓或清仓
> - 信号消失即离场：买入依据的技术信号一旦破坏，立即离场

## 一、执行前二次核对

> 来自 `AI量化投资流水线(1).md` ⑨ 调仓执行——"执行前二次核对：仓位、风控约束、价格区间"。

| 核对项 | 规则 | 不通过处理 |
| --- | --- | --- |
| 仓位核对 | 单票 ≤ 10%、单行业 ≤ 30%、总仓位 ≤ 80% | 拒绝执行，退回 ⑥ 组合构建 |
| 风控约束 | 信仰手册 R1-R5 全部通过 | 拒绝执行，退回 ⑧ 风险检查 |
| 价格区间 | 当前价在买入价区间 [low, high] 内 | 等待回踩或调整价格区间 |
| ST/停牌 | 不得持有 ST/停牌股票 | 立即剔除 |
| 持仓天数 | 现有持仓无超 T+3 标的 | 超 T+3 先平仓再建仓 |

## 二、卖点体系（原 sell-point-determination 整合）

### 核心卖出信号（触发任一即卖出）

#### 1. 止盈卖出（分级止盈）

```
第一级（保守）：涨幅 ≥ 3%  → 卖出 1/3 仓位（短线不贪多）
第二级（进取）：涨幅 ≥ 5%  → 卖出 1/2 仓位
第三级（激进）：涨幅 ≥ 10% → 全部清仓（或保留底仓 10%）

注意：止盈位需结合个股波动率调整
  - 高波动股（20日波动率 > 30%）：止盈位上浮 5%
  - 低波动股（20日波动率 < 15%）：止盈位下调 3%
```

> **信仰手册约束**（1.3 节）：止盈位通常为 3-5%（短线不贪多）。

#### 2. 止损卖出

```
硬止损（无例外）：
  ✅ 亏损 ≥ 2%（信仰手册红线，绝对止损线）
  ✅ 跌破 MA20 且放量（成交量 > 5日均量 × 1.2）

软止损（满足两项）：
  ✅ 连续3日收盘价低于 MA10
  ✅ 行业指数跌破 10 日均线
```

> **信仰手册约束**（1.3 节）：止损位为 -2%（严格止损，亏损不拖）。

#### 3. 趋势破坏卖出

```
触发条件（满足任一）：
  ✅ 股价跌破 MA20 且 3 日内未能收复
  ✅ 所属行业指数跌破 MA20
  ✅ 大盘（上证指数）跌破 MA60
  ✅ 成交量异常放大（> 5日均量 × 2.0）且股价下跌
```

#### 4. T+3 强制平仓

```
持仓时间监控（信仰手册核心红线）：
  ✅ 持仓达 T+2 收盘前 → 检查走势，未达预期则减仓/清仓
  ✅ 持仓达 T+3 → 系统自动标记并强制平仓，防止短线变长线
```

### MA20 均线卖出（核心规则）

> **硬约束 H5**：买入/卖出判断必须依赖 20 日均线（MA20），不得仅凭基本面得分直接给出操作建议。

```
股价 > MA20 → 持有（趋势向上）
股价 = MA20 ± 1% → 观察（警惕变盘）
股价 < MA20 → 卖出（趋势破坏）
股价 < MA20 且放量 → 立即卖出（趋势确认破坏）
```

### 分批卖出策略

```
第一目标位（3%）：卖出 30%
第二目标位（5%）：卖出 30%
第三目标位（10%）：卖出 30%
底仓（10%）：跟随 MA20 动态止盈

若股价未达目标位就跌破 MA20 → 立即清仓，不等待目标位
```

## 三、实时监控（七大预警规则）

**工具**: `src/monitor/monitor.py`

```python
from src.monitor.monitor import StockAlert
alert_system = StockAlert(log_to_file=True, log_to_console=False)
result = alert_system.run_once(smart_mode=True)
```

| # | 预警规则 | 触发条件 | 处理 |
| --- | --- | --- | --- |
| 1 | 成本百分比 | 盈利 +15% / 亏损 -12% | 触发止盈/止损 |
| 2 | 日内涨跌幅 | 个股 ±4% | 监控异动 |
| 3 | 成交量异动 | 放量 > 2倍均量 | 检查主力动向 |
| 4 | 均线金叉/死叉 | MA5 上穿/下穿 MA10 | 趋势信号 |
| 5 | RSI 超买超卖 | RSI > 70 / RSI < 30 | 反转预警 |
| 6 | 跳空缺口 | 向上/向下跳空 > 0.5% | 缺口回补监控 |
| 7 | 动态止盈 | 盈利 10%+ 后回撤 5%/10% | 利润保护 |

> **短线版本调整**：信仰手册要求止损 -2%、止盈 3-5%，预警规则 1 的阈值需按信仰手册调整（亏损 -2% 而非 -12%，止盈 3-5% 而非 +15%）。

## 执行步骤

```
Step 1: 读取 ⓪人工审查④放行的持仓方案
  └─ output/portfolio-construction/portfolio.json

Step 2: 执行前二次核对
  ├─ 仓位核对（单票≤10%、单行业≤30%、总仓位≤80%）
  ├─ 风控约束核对（信仰手册R1-R5）
  ├─ 价格区间核对（当前价在买入区间内）
  ├─ ST/停牌核对
  └─ 持仓天数核对（无超T+3标的）

Step 3: 生成委托指令
  ├─ 记录每笔委托时间、股票代码、买入/卖出、价格、股数、金额
  └─ 标注操作理由（打分得分、风控放行结论、信号类型）

Step 4: 执行调仓
  ├─ 买入：按持仓方案的仓位比例执行
  └─ 卖出：检查现有持仓的卖出信号，触发即执行

Step 5: 启动实时监控
  ├─ 设置监控名单（watchlist）
  ├─ 启动七大预警规则
  ├─ 启动卖点信号监控（止盈/止损/趋势破坏/T+3强制平仓）
  └─ 触发预警 → 生成 alert → 记录到 alerts.json

Step 6: 输出执行记录 + 监控数据
  ├─ output/rebalance-execution/orders.json（委托记录）
  └─ output/rebalance-execution/alerts.json（预警信号）
```

## 注意事项

1. **所有操作必须可追溯**（来自 `AI量化投资流水线(1).md` + 信仰手册 1.4 节）：记录每一笔委托时间、成交价格、操作理由，禁止无依据临时交易。
2. **执行前二次核对不可省略**（来自 `AI量化投资流水线(1).md`）：仓位、风控约束、价格区间三项核对全部通过后方可执行。
3. **信仰手册止损红线 -2%**：止损位为 -2%（严格止损），非原 sell-point 的 -8%。短线交易亏损不拖。
4. **信仰手册止盈 3-5%**：止盈位通常为 3-5%（短线不贪多），非原 sell-point 的 15-20%。
5. **T+3 强制平仓**（信仰手册核心红线）：任何持仓超过 3 个交易日，系统自动标记并强制平仓，防止短线变长线。
6. **禁止情绪化交易**（信仰手册 1.3 节）：所有卖出操作必须有触发理由（止盈/止损/趋势破坏/T+3），禁止"感觉要跌"就卖。
7. **信号消失即离场**（信仰手册 1.3 节）：买入依据的技术信号一旦破坏（如放量滞涨、跌破当日低点），立即离场，不抱侥幸心理。
8. **MA20 是卖出判断核心**（硬约束 H5）：跌破 MA20 必须减仓，无论基本面多好。
9. **当前实现状态**：买入执行 + 卖点监控由 `src/monitor/monitor.py` 承接，委托记录模块待完善。
