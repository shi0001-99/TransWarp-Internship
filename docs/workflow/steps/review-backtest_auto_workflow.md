## 一、回测校验

### 回测流程

```
Step 1: 选取历史时间窗口（默认近60个交易日）

Step 2: 在每个交易日 T 执行：
  ├─ 用 T-1 日收盘数据跑 stock-scoring 子流程
  ├─ 得到 Top N 组合，记录买入价（T 日开盘价）
  ├─ 按卖出规则跟踪持仓：
  │   ├─ 止盈：涨幅达 15%-20%
  │   ├─ 止损：跌破 MA20 且放量
  │   └─ 趋势消退：行业指数跌破10日均线
  └─ 记录每笔交易的买入日、卖出日、收益、持仓天数

Step 3: 统计回测指标
  ├─ 总收益率
  ├─ 年化收益率
  ├─ 最大回撤
  ├─ 胜率（盈利交易数 / 总交易数）
  ├─ 盈亏比（平均盈利 / 平均亏损）
  └─ 行业集中度（单行业占比上限 40%）
```

### 回测通过标准

| 指标 | 达标线 | 不达标处理 |
|------|--------|-----------|
| 年化收益率 | ≥ 15% | 退回打分模块，调整因子权重 |
| 最大回撤 | ≤ 15% | 退回组合构建，增加分散度 |
| 胜率 | ≥ 55% | 退回打分模块，收紧买入条件 |
| 盈亏比 | ≥ 1.5 | 退回打分模块，调整止盈止损位 |
| 行业集中度 | 单行业 ≤ 40% | 退回组合构建，强制分散 |

## 二、风险检查

### 检查清单

| # | 检查项 | 规则 | 不通过处理 |
|---|--------|------|-----------|
| R1 | 单票仓位 | ≤ 30% | 超限部分强制减仓 |
| R2 | 组合持仓数 | = 10 只 | 不足则从观察池补入，超出则裁剪低分标的 |
| R3 | 行业集中度 | 单行业 ≤ 40% | 超限行业按得分从低到高剔除 |
| R4 | ST/停牌检查 | 不得持有 | 发现立即剔除 |
| R5 | 流动性检查 | 日均成交额 ≥ 5000万 | 不达标直接剔除 |
| R6 | 大盘择时 | 上证指数跌破 MA60 → 空仓 | 触发时全部清仓观望 |

### 大盘择时规则（分层仓位管理）

```
上证指数 > MA20  → 正常仓位（100%）
上证指数 跌破 MA20 但 > MA60 → 降至 50% 仓位
上证指数 跌破 MA60 → 空仓观望（0%）
```

## 三、归因复盘

### 复盘频率

- **每周五收盘后**：周度复盘
- **每月最后一个交易日**：月度深度复盘

### 归因拆解

```
总收益 = 赛道贡献 + 个股 Alpha + 择时收益 + 随机误差

赛道贡献 = 行业平均涨幅 × 仓位权重
个股 Alpha = 个股涨幅 - 行业平均涨幅
择时收益 = 实际持仓收益 - 满仓持有收益
```

### 复盘文档模板

```markdown
# 投资复盘日志 {date}

## 1. 本期组合表现
- 总收益率：X%
- 基准（沪深300）：X%
- 超额收益：X%
- 最大回撤：X%

## 2. 收益归因
| 来源 | 贡献 | 说明 |
|------|------|------|
| 赛道贡献 | X% | 哪个行业贡献最大 |
| 个股 Alpha | X% | 哪只股票超额最多 |
| 择时收益 | X% | MA20 择时是否有效 |

## 3. 操作回顾
| 股票 | 买入日 | 卖出日 | 收益 | 卖出原因 | 事后评价 |
|------|--------|--------|------|----------|----------|

## 4. 教训与改进
- 规则是否被遵守？（有无情绪化交易）
- 哪条规则需要调整？（如止盈位、MA 周期）
- 下周重点关注的赛道和个股

## 5. 方法论更新
- 需要修改打分规则的地方 → 更新 docs/stock-scoring.md
- 需要修改风控规则的地方 → 更新本文件
```

### 闭环规则

```
复盘结论 → 更新《投资信仰手册》（投资知识/）
         → 更新打分因子权重（docs/stock-scoring.md）
         → 更新风控规则（docs/review-backtest.md）
         → 下一轮选股使用新规则
```

> **硬约束 H6**：所有交易必须可追溯。复盘时如果发现"无依据临时交易"，需在复盘日志中标记并反思。

---

## 注意事项

1. **回测不是万能的**：历史表现好不等于未来好，回测通过后仍需人工审阅组合合理性。
2. **风控一票否决**：风险检查不通过，禁止进入实盘/模拟调仓，没有例外。
3. **复盘必须闭环**：发现问题 → 更新规则 → 下一轮验证，不能只记录不改进。
4. **区分运气与方法论**：收益来自行业普涨（运气）还是个股选择（方法论），归因时要分开。
5. **子流程文档引用**：打分规则变更需更新 `docs/stock-scoring_auto_workflow.md`，风控规则变更需更新本文件。
