# 子流程：④ 公司研究

> **对应流水线环节**：④ 公司研究｜Agent层
> **前置文档**：`main_auto_workflow.md`、`info-collection_auto_workflow.md`、`TransAlpha小组投资信仰手册.md`、`TransAlpha赛道景气度打分表.md`
> **后置环节**：⓪ 人工审查② → ⑤ 因子打分

---

## 目标

基于 ③ 信息收集产出的全市场数据台账，对候选股票进行**个股深度研究**，拆分研究任务（基本面、竞争格局、业绩催化、风险点），输出个股深度调研报告，作为打分环节的原始依据。

> **设计依据**：
> - `AI量化投资流水线(1).md` ④ 公司研究——"拆分研究任务：基本面、竞争格局、业绩催化、风险点；人工完成个股深度研究报告，明确企业核心壁垒"
> - `TransAlpha小组投资信仰手册.md` 1.1 节"选股逻辑：资金驱动 + 技术形态 + 短线催化。不依赖长线基本面，聚焦短期市场情绪、资金流向与技术共振"
> - `TransAlpha赛道景气度打分表.md` 1.2 节"六维热度打分模型"——资金驱动力、连板高度、技术形态、催化强度、龙头辨识度、市场认可度

---

## 输入

从 ③ 信息收集环节接收以下数据：

| 输入项 | 格式 | 说明 |

## 研究框架

### 一、研究任务拆分（四维度）

> 来自 `AI量化投资流水线(1).md` ④ 公司研究的四个研究方向。

#### 1. 基本面研究

| 研究项 | 关注点 | 数据来源 |
| --- | --- | --- |
| 盈利能力 | ROE、毛利率、净利率趋势 | 财报数据（`fetch_fundamental()`） |
| 成长性 | 营收增速、净利润增速、环比变化 | 财报数据 |
| 现金流质量 | 经营性现金流 vs 净利润、自由现金流 | 财报数据 |
| 资产质量 | 资产负债率、应收账款、存货周转 | 财报数据 |

> **信仰手册约束**：短线交易"不依赖长线基本面"，但基本面用于排除"绝对不行的公司"（质量筛查），而非追求全面深度。

#### 2. 竞争格局研究

| 研究项 | 关注点 | 数据来源 |
| --- | --- | --- |
| 行业地位 | 市占率、行业排名 | 行业研报 |
| 核心壁垒 | 技术/品牌/渠道/资源壁垒 | 个股研报 |
| 竞争对手 | 同行业可比公司对比 | 行业分类数据 |

#### 3. 业绩催化研究

| 研究项 | 关注点 | 数据来源 |
| --- | --- | --- |
| 短线催化剂 | 政策利好、业绩预告、事件驱动（并购/中标/新产品） | 赛道打分表"催化强度"维度 |
| 资金信号 | 主力资金净流入、北向资金动向、龙虎榜席位 | `fetch_batch_northbound()` + `fetch_batch_dragon_tiger()` |
| 技术形态 | 均线排列、量价配合、突破/回踩信号 | K线历史数据 |

> **信仰手册约束**：选股逻辑为"资金驱动 + 技术形态 + 短线催化"，本维度是短线交易的核心。

#### 4. 风险点研究

| 研究项 | 关注点 | 数据来源 |
| --- | --- | --- |
| 估值风险 | PE/PB 是否偏离行业均值 | 估值评估指标 |
| 解禁风险 | 近期限售股解禁日期和规模 | 公告数据 |
| 商誉风险 | 商誉占净资产比例 | 财报数据 |
| 情绪风险 | 换手率异常、连板高度过高（追高风险） | 实时行情 |

### 二、短线交易专属研究（依据信仰手册）

> 信仰手册明确"超短线交易，持仓周期 ≤ 3 天"，因此公司研究聚焦短线维度。

#### 龙头辨识（依据赛道打分表"龙头辨识度"维度）

| 龙头类型 | 识别标准 | 研究关注点 |
| --- | --- | --- |
| 总龙头 | 市场最高连板、全市场情绪风向标 | 封板强度、量能配合、次日溢价预期 |
| 空间龙头 | 板块内涨幅最大、打开上涨空间 | 突破压力位、量能放大、板块带动效应 |
| 卡位龙头 | 板块补涨龙头、接力总龙头 | 资金切换信号、技术形态确立 |

#### 资金驱动力研究（依据赛道打分表"资金驱动力"维度，权重25%）

```
资金驱动力评分 =
  主力资金净流入排名 (40%)
  + 北向资金单日净买入额 (30%)
  + 融资余额增速 (30%)
```

> 资金是推动股价的直接动力，短线核心指标。

#### 技术形态研究（依据赛道打分表"技术形态"维度，权重20%）

| 检查项 | 判断标准 |
| --- | --- |
| 均线多头排列 | 股价 > MA5 > MA10 > MA20 |
| MACD 金叉 | DIF 上穿 DEA |
| 量能放大 | 成交量 > 5日均量 × 1.5 |
| 突破压力位 | 股价突破近期高点或筹码密集峰上沿 |

## 执行步骤

```
Step 1: 读取 ③ 信息收集输出的全市场数据台账
  └─ output/info-collection/market_data.json

Step 2: 根据⓪人工审查①确认的候选池，筛选待研究股票
  ├─ 板块总分 ≥ 55（观察参与及以上）的板块内股票优先
  └─ 排除板块总分 < 55（禁止参与）的板块内所有股票

Step 3: 对每只候选股票执行四维度研究
  ├─ 基本面研究：调用 fetch_fundamental() 获取财报数据
  ├─ 竞争格局研究：基于行业分类数据 + 行业研报
  ├─ 业绩催化研究：资金信号 + 技术形态 + 短线催化剂
  └─ 风险点研究：估值风险 + 解禁风险 + 商誉风险 + 情绪风险

Step 4: 短线交易专属研究
  ├─ 龙头辨识：识别总龙头/空间龙头/卡位龙头
  ├─ 资金驱动力评分（六维模型25%权重维度）
  └─ 技术形态确认（均线/MACD/量能/突破）

Step 5: 生成个股深度研究报告
  ├─ 企业核心壁垒总结
  ├─ 短线催化因素清单
  ├─ 风险点警示
  └─ 研究结论：是否进入打分环节

Step 6: 输出研究报告 → output/company-research/research_reports.json
  └─ 传递给 ⓪ 人工审查②
```

## 注意事项

1. **短线优先**（来自信仰手册）：公司研究聚焦短线维度（资金驱动 + 技术形态 + 短线催化），不追求长线基本面的全面深度。基本面用于排除"绝对不行的公司"。
2. **板块优先**（来自信仰手册 1.3 节"板块优先"）：选股顺序为"板块热度 → 龙头个股 → 技术形态"，不在冷门板块里挖"金子"。板块总分 < 55 的股票不研究。
3. **追强不抄底**（来自信仰手册 1.3 节）：只研究强势股、热点板块龙头，绝对不碰下跌趋势中的反弹。强势股定义：5日均线向上、成交量放大、板块热度排名前三。
4. **研究结论须人工确认**：本环节输出的研究结论需经⓪人工审查②确认，人类决定哪些股票进入 ⑤ 因子打分。
5. **企业核心壁垒必须明确**（来自 `AI量化投资流水线(1).md`）：每份研究报告必须明确企业核心壁垒，作为打分原始依据。
6. **信息溯源**（来自 `AI量化投资流水线(1).md`）：研究报告中的任何结论必须标注来源、数据时间，区分高/低可信度信息。
7. **禁止模拟数据**（来自信仰手册 1.4 节）：API 不可用时返回空列表，严禁生成伪造研究报告。
