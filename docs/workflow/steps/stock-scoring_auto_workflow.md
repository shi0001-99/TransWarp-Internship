# 子流程：⑤ 因子打分

> **对应流水线环节**：⑤ 因子打分｜决策层
> **前置文档**：`main_auto_workflow.md`、`info-collection_auto_workflow.md`、`company-research_auto_workflow.md`
> **后置环节**：⑥ 组合构建
> **输出目录**：`output/factor-scoring/top10_stocks.json`

---

## 目标

对数据收集阶段产出的股票池进行多维度打分，输出 Top N 选股结果（含四大流派得分、CH-4因子暴露和各项小分明细）、个股分析报告、买卖操作建议。

**核心架构：基本面筛选 + 四流派打分 + CH-4因子融合**

> **理论依据**：基于《股票买卖点与仓位管理全景调研报告》中**前四大流派**的取舍权重方案A：
> - **流派3：基本面估值与业绩拐点**（40%）— 买什么，CH-4 EP/VMG 核心
> - **流派1：趋势与动量类技术分析**（20%）— 何时买，均线/动量/波动率
> - **流派2：量价、筹码与支撑阻力**（15%）— 信号确认，筹码集中度/峰形/支撑阻力
> - **流派4：资金面与行为金融**（25%）— 买多少、何时卖，北向/龙虎榜/处置效应纠偏
>
> 四者不是竞争关系而是时间频谱互补：基本面选股 alpha → 趋势择时 → 筹码确认 → 资金面行为纠偏仓位。

| 维度 | 流派 | 权重 | 核心内容 |
|---|---|---|---|
| **基本面(40)** | 流派3 基本面估值 | 40分 | ROE(10) + 营收增速(10) + 现金流(8) + 价值因子EP(7) + 股息率(5) |
| **趋势动量(20)** | 流派1 趋势动量 | 20分 | 均线多头(8) + 动量反转(6) + 波动率ATR(3) + 行业热度(3) |
| **量价筹码(15)** | 流派2 量价筹码 | 15分 | 筹码集中度(5) + 量价配合(5) + 支撑阻力(5) |
| **资金面行为(25)** | 流派4 资金行为 | 25分 | 基础20分×1.25映射（主力吸筹+资金合力+筹码健康+行为锚定）+ 北向/龙虎榜增强 |
| **CH-4 因子** | 横截面定价基准 | 融合层 | traditional(60%) + ch4_scaled(40%) |

> **CH-4 补充说明**：《Size and Value in China》(JFE 2019) 论文证明中国市场 EP 因子完全吸收 B/P 因子，且需剔除最小30%壳价值污染，并引入异常换手率情绪因子。本系统据此重构了估值打分和筛选逻辑。

## 筛选与打分体系

### 第一步：基本面筛选（唯一入围门槛）

系统使用**基本面作为唯一筛选门槛**，只有通过基本面筛选的股票才会进入三维度打分。

| 检查项 | 筛选逻辑 | 行业自适应 |
|--------|----------|------------|
| ST 排除 | 名称含 ST/\*ST/退 则剔除 | 强制 |
| **壳价值过滤（CH-4）** | **全市场市值最小30%分位 + 营收<5亿 + 亏损 → 剔除** | **强制（横截面分位）** |
| ROE | `roe ≥ thresholds.roe_min` | 国有大行≥10%，股份制银行≥12%，白酒≥18%，半导体≥3% |
| 净利润增长率 | 同比增速 > -30% | 严重下滑则剔除 |
| 自由现金流 | 经营现金流为正 | 金融/半导体豁免（`cash_flow_exempt=True`） |
| 资产负债率 | `debt_ratio ≤ thresholds.debt_ratio_max` | 国有大行≤95%，白酒≤50% |

> **硬约束 H1**：行业自适应必须按二级分类（`industry_level2`）执行，禁止用一级分类或统一阈值。
>
> **硬约束 H7（CH-4 论文要求）**：壳价值过滤必须基于**全市场横截面市值分位数**（最小30%），禁止用固定市值阈值。过滤逻辑严格遵循 Liu-Stambaugh-Yuan (2019) 论文，避免 IPO 限制导致的壳价值污染对规模因子的破坏。

### 第二步：四流派评分（满分100分）

通过基本面筛选后，系统对每只股票进行四流派量化打分（对应调研报告方案A权重）：

---

### 基本面得分（40分） —— 流派3：基本面估值与业绩拐点

| 因子 | 分值 | 评分逻辑 | 行业自适应 |
|------|------|----------|-----------|
| ROE | 10分 | 达行业阈值满分，每降1%扣0.5分；低于70%阈值得3分 | 国有大行≥10%，股份制银行≥12%，白酒≥18%，半导体≥3% |
| 营收增速 | 10分 | ≥30%→10分，≥15%→8分，≥5%→6分，≥0%→4分，<0%→2分 | 科技/新能源≥30%，周期≥20%，消费≥10% |
| 自由现金流 | 8分 | 连续3年为正→8分，为正但非连续→5分，为负→0分 | 金融/半导体豁免，给满分 |
| **价值因子EP（CH-4）** | 7分 | **EP横截面分位≥70%→7分；50%-70%→5.5分；30%-50%→4分；<30%→2分；亏损股→1分** | **全市场横截面分位（无行业自适应）** |
| 股息率 | 5分 | 达行业阈值→5分，达50%阈值→3分，低于→1分 | 银行≥4%，公用事业≥3%，科技/周期≥1% |

> **CH-4 因子说明**：价值因子严格遵循论文使用 **EP = Earnings/Price**（PE的倒数），而非传统 Fama-French 的 B/P（账面市值比）。论文实证表明，在中国市场 EP 因子完全吸收 B/P 的解释力，若用 B/P 会损失约17%的年化 alpha。
>
> **阶段2 EP 严格计算**：优先使用 `EP = 扣非净利润 / (上月末收盘价 × 总股本)`（论文公式），扣非净利润数据来自 `data_fetcher.fetch_fundamental()` 中的 `net_profit_excl_nonrecurring` 字段。数据不可用时自动回退到 1/PE。
>
> **横截面分位计算**：在全市场快照（已剔除壳股）中按 EP 排序，计算当前股票 EP 在所有有效 EP（>0）样本中的分位数。亏损股（EP≤0）直接给予1分最低分。
>
> **回退机制**：当全市场快照构建失败或样本数<50时，自动回退到行业 PE 区间打分（保守降级）。
>
> **代码实现**：`screener.py` → `_calc_fundamental_score()` + `factor_model.py` → `CH4FactorModel.get_ep_percentile()` + `CH4FactorModel._calc_ep_strict()`

### 趋势动量得分（20分） —— 流派1：趋势与动量类技术分析

> 趋势动量**仅用于打分排序**，不再作为筛选条件。所有通过基本面的股票都会计算趋势动量得分。覆盖 MA/均线排列、动量反转、ATR波动率、行业热度四大维度。

| 因子 | 分值 | 评分逻辑 | 数据来源 |
|------|------|----------|----------|
| 均线多头排列 | 8分 | bullish(price>MA5>MA10>MA20)→8分；semi_bullish→6分；neutral→4分；bearish→1分 | 历史K线（120日） |
| 趋势动量(含反转) | 6分 | 5日>5%+20日>10%→6分；5日>0+20日>5%→5分；5日>0→4分；5日<-10%+20日>-5%（超跌反转）→额外+1.5分 | 历史K线 |
| 波动率ATR | 3分 | 年化波动<15%→3分；<25%→2.5分；<35%→1.5分；其他→0.5分 | 历史K线（20日收益率） |
| 行业热度 | 3分 | 近5日涨幅>10%→3分；>5%→2.5分；>0%→2分；>-5%→1分；其他→0.5分 | 个股5日涨幅（代理行业热度） |

> **硬约束 H5**：即使综合得分很高，如果均线排列不是 bullish，投资建议只能是"观察为主"，不能给买入建议。
>
> **代码实现**：`screener.py` → `_calc_trend_score()`

### 量价筹码得分（15分）—— 流派2：量价、筹码与支撑阻力

> 基于K线历史（120日）自行构建筹码分布，识别单峰/双峰密集、筹码集中度（CR10）、量价配合形态和筹码密集峰构成的天然支撑/阻力位。数据源优先考虑 akshare `stock_cyq_em` 接口（东方财富筹码分布），当接口不可用时自动回退到**换手率衰减模型**自行计算筹码分布。

#### 筹码分布构建方法

| 方法 | 说明 |
|---|---|
| **akshare直接获取（优先）** | `stock_cyq_em(symbol, start_date, end_date)` 返回含集中度(90%/70%)、主力成本、获利比例、套牢盘比例等完整字段 |
| **换手率衰减模型（回退）** | 120日K线成交量按价格区间80个bin均匀分布，历史成交量按半衰期60日指数衰减 `exp(-ln(2)·天数/60)`，叠加日换手率=当日成交量/流通股本加权 |

#### 满分15分：三大维度各5分

| 维度 | 子项 | 分值 | 评分逻辑 |
|---|---|---|---|
| **筹码集中度（5分）** | CR10集中度 | 2分 | ≤15%→2分；≤20%→1.5分；≤25%→1分；≤30%→0.5分；>30%→0分 |
| | 峰形识别 | 2分 | 单峰+low→2分；单峰+mid→1.5分；双峰+下峰支撑→1分；单峰+high→0.5分；多峰/unknown→0.5分 |
| | 底部筹码占比 | 1分 | 下1/3筹码>50%→1分；>30%→0.5分；其他→0分 |
| **量价配合度（5分）** | 放量突破 | 2分 | MA20突破+量比>2→2分；MA20突破+量比>1.5→1.5分；非MA20突破但量比>1.8→1分；否→0分 |
| | 缩量回踩 | 1分 | 近5日有回踩且量<MA20→1分；否→0分 |
| | 放量滞涨 | 1分 | 量>1.15×MA20 且 |涨跌|<1%→0分(扣分项)；正常→1分 |
| | 量价背离 | 1分 | 近5日涨+量减>0.5×MA→0分(扣分项)；无→1分 |
| **支撑阻力位（5分）** | 支撑位距离 | 2分 | 距支撑≤3%→2分；≤5%→1.5分；≤8%→1分；≤10%→0.5分；其他→0分 |
| | 阻力位距离 | 1分 | 距阻力≥8%→1分；≥5%→0.7分；≥3%→0.5分；其他→0分 |
| | 缺口支撑 | 1分 | 20日内存在缺口且价回踩缺口上沿→1分；否→0分 |
| | 密集峰支撑 | 1分 | 价在密集峰上沿附近（low/mid）→1分；mid→0.7分；near_resistance→0分 |

#### 筹码买卖信号逻辑（用户指定的 3 买 3 卖）

**🟢 买入信号（任一触发即记入 `buy_signals`）**

| 编号 | 触发条件 | 完整判定公式 |
|---|---|---|
| B1 | **低位单峰密集+放量突破** | `is_single_peak AND peak_pos==low AND CR10<15% AND volume_breakout(MA20+量比>1.8)` |
| B2 | **双峰中下峰不破+缩量回踩** | `is_double_peak AND shrink_pullback AND bottom_chip_ratio > 50% AND price > lower_peak_price × 0.98` |
| B3 | **V形反转前密集峰未被消耗** | `price 突破 dense_upper_edge AND bottom_chip_ratio > 55% AND volume_ratio > 1.5` |

**🔴 卖出信号（任一触发即记入 `sell_signals`）**

| 编号 | 触发条件 | 完整判定公式 |
|---|---|---|
| S1 | **高位单峰密集+底部筹码消失** | `is_single_peak AND peak_pos==high AND bottom_chip_ratio < 30%` |
| S2 | **筹码发散+放量滞涨** | `CR10 < 12% AND stagnation(量>1.2×MA5 且 \|涨跌\|<1%)` |
| S3 | **上峰不移下跌不止** | `price 跌破 dense_lower_edge AND upper_trapped_ratio > 40%` |

> **代码实现**：`volume_price_analyzer.py` → `VolumePriceAnalyzer.score()` + `_calc_chip_distribution()` + `_find_peaks_robust()` + `_detect_buy_signals()` + `_detect_sell_signals()`

### 资金面行为得分（25分）—— 流派4：资金面与行为金融

> 资金面基于**已有K线历史数据（120日）和实时行情**推断为主，阶段2可选接入**北向资金**和**龙虎榜**数据作为加分项。采用四维度评估体系 + 两个可选增强项，覆盖主力行为、资金合力、筹码结构和投资者行为学。
>
> **权重映射**：基础四维度原满分20分，按方案A权重映射为满分25分（×1.25缩放，即原20分→新25分），增强项仍单独加在基础得分上。

#### 核心四维度评分（基础满分20分 → 映射后25分）

| 维度 | 原分值 | 映射分值(×1.25) | 核心逻辑 | 数据来源 |
|------|------|------|----------|---------|
| **主力吸筹信号** | 6分 | 7.5分 | 缩量回踩均线支撑（智能交易蓝线MA20）+ 放量突破 + 封板质量 | K线历史(量价) + 实时行情 |
| **资金合力检测** | 5分 | 6.25分 | 量价配合度（放量上涨=合力；放量滞涨=分歧）+ 资金持续性 | K线历史(量价趋势) |
| **筹码健康度** | 5分 | 6.25分 | 锁仓检测(低换手横盘) + 出货检测(放量不涨) + 一家独大检测(超高换手) | K线历史 + 实时换手率 |
| **行为学锚定信号** | 4分 | 5分 | 处置效应(盈利/亏损状态下换手率异常) + 锚定效应(52周位置+量能) | K线历史(52周高低点) |
| **合计** | 20分 | **25分** | | |

#### 可选增强项（阶段2新增，各最高+2分，叠加在25分之上）

| 增强项 | 最高加分 | 评分逻辑 | 数据来源 |
|--------|---------|---------|---------|
| **北向资金加分** | +2分 | 连续3日净买入≥5000万→+2分；连续3日但金额小→+1分；连续2日→+0.5分 | 东方财富API |
| **龙虎榜加分** | +2分 | 紫旗(机构+游资合力净流入)→+2分；上榜净买入为正→+1分 | 东方财富API |

> **双合力强信号**：当北向连续3日净买入 + 龙虎榜紫旗时，仓位建议直接升级为"强烈建仓"。
>
> **卖出信号增强**：北向单日净卖出≥1亿 → 仓位建议降级为"回避"；龙虎榜净流出 → 标注"抛压明显"。
>
> **兼容性**：无北向/龙虎榜数据时，基础四维度仍为25分满分，系统行为不降级。

| 10-15分 | 🔍 轻仓观察 | 资金面偏弱 |

| 超高换手(>15%)+低分 | 🔔 轻仓试错 | 一家独大，游资打板成功率仅42-44% |
| 北向净卖出≥1亿 | ⛔ 北向资金净卖出，建议回避 | 阶段2增强：北向资金卖出信号 |
| 龙虎榜净流出 | ⛔ 龙虎榜净流出，抛压明显 | 阶段2增强：龙虎榜卖出信号 |

#### 关键行为学发现（用户研究结论）

> **投资者处置效应**：登录账户后看到盈利更容易卖出，亏损更易持有，导致"卖飞好股、死扛烂股"。系统通过**高位放量下跌**检测获利了结压力，通过**低位缩量横盘**检测死扛风险。
>
> **锚定效应**：高风险偏好投资者对新参考点形成（如登录价格、52周高点）会推高卖出倾向。系统通过52周位置结合量能变化，识别锚定效应导致的非理性交易行为。

> **代码实现**：`capital_flow_analyzer.py` → `CapitalFlowAnalyzer.score()` + `_score_northbound_bonus()` + `_score_dragon_tiger_bonus()`；20→25分缩放由 `screener.py` → `_analyze_stock()` 中 `capital_score = vp_scaled × 1.25` 实现。

### CH-4 因子融合（Liu-Stambaugh-Yuan 2019）

在传统三维度打分之外，系统引入 CH-4 中国四因子模型作为横截面定价基准，与传统打分融合产生最终综合得分。

#### 四因子定义

| 因子 | 符号 | 严格定义（论文公式） |
|------|------|--------------------|
| 市场因子 | `RMRF` | A股市值加权收益率 - 无风险利率 |
| 规模因子 | `SMB` | **剔除最小30%壳公司后**，小盘组合收益 - 大盘组合收益 |
| 价值因子 | `VMG` | Value-Minus-Growth：按 EP 排序，高EP组合 - 低EP组合（规模中性化） |
| 情绪因子 | `PMG` | Pessimistic-Minus-Optimistic：按异常换手率排序，低换手组合 - 高换手组合 |

#### 因子暴露计算

每只股票计算四因子的横截面 z-score 标准化暴露值：

```
# 因子1：Size（市值log，取反后小盘得分高）
size_score      = -z_score(log(market_cap))

# 因子2：Value（EP横截面分位z-score，阶段2严格定义）
# EP = 扣非净利润 / (上月末收盘价 × 总股本)   ← 论文公式
# 回退：1/PE（当扣非净利润不可用时）
ep_strict       = net_profit_excl_nonrecurring / (last_month_close × total_shares)
value_score     = +z_score(ep_strict)

# 因子3：Sentiment（异常换手率，取反后低换手得分高）
abnormal_turnover = today_turnover / ma_60_turnover
sentiment_score = -z_score(abnormal_turnover)

# 因子4：Market Beta（个股相对市场波动比）
market_beta     = estimate_beta(history_returns)

# 加权合成
composite_score = 0.25·market_beta + 0.25·size_score 
                + 0.30·value_score + 0.20·sentiment_score
```

> **阶段2 EP 计算增强**：论文严格定义 EP = 扣非净利润 / (上月末收盘价 × 总股本)。系统优先使用此公式计算，当扣非净利润数据不可用时自动回退到 1/PE（阶段1兼容方案）。

#### 综合得分融合公式

```
traditional_total = fundamental_score(40) + trend_score(20) 
                  + volume_price_score(15) + capital_score(25)   # 满分100
ch4_scaled        = clip(50 + composite_score × 20, 0, 100)               # z-score缩放到0-100

total_score = 0.6 × traditional_total + 0.4 × ch4_scaled                 # 融合得分
```

> **融合权重说明**：传统四流派打分60% + CH-4因子40% 是保守起点。传统打分覆盖了 ROE/营收/现金流/股息率/均线/筹码/行为学等论文未涉及的多维度信息，CH-4 因子则提供横截面定价基准，两者互补。
>
> **权重说明**：按方案A权重（基本面40 + 趋势动量20 + 量价筹码15 + 资金面行为25）合计100分。资金面原20分通过 ×1.25 线性缩放到25分（20×1.25=25）。
>
> **回退机制**：当 `enable_ch4_factor=False`、`factor_model=None` 或 `universe_snapshot=None` 时，自动回退到纯传统打分（`total_score = traditional_total`），保证系统可用性。
>
> **代码实现**：`screener.py` → `_analyze_stock()` 融合逻辑 + `factor_model.py` → `CH4FactorModel.compute_factor_exposure()`

#### 全市场快照构建流程

```
Step 1: build_universe_snapshot(stocks, quotes)
        → 构建DataFrame: code, market_cap, log_market_cap, ep, pe, price, turnover_rate

Step 2: filter_shell_stocks(universe)
        → 剔除市值 < quantile(0.30) 的股票（壳价值过滤）

Step 3: 对每只股票调用 compute_factor_exposure()
        → 横截面 z-score 标准化计算四因子暴露

Step 4: 输出 ch4_factors 字段，包含：
        - market_beta, size_score, value_score, sentiment_score, composite_score
        - raw_factors: log_market_cap, ep, abnormal_turnover
        - interpretation: 人类可读的因子解读标签
```

> **缓存策略**：全市场快照应在 `pipeline.py` 中每日构建一次并缓存，避免每次选股重复计算。当前阶段1暂未实现缓存，每次 `run_screening` 都会重新构建。

## 买卖建议规则

### 买入信号（全部满足 + 筹码确认增强）

```
【第一关：基本面筛选 —— 系统自动执行，不满足直接排除】
  ✅ ST/*ST 排除
  ✅ 壳价值过滤（CH-4）：市值 ≥ 全市场30%分位 或 营收≥5亿 或 盈利
  ✅ ROE ≥ 行业阈值（按二级分类自适应）
  ✅ 净利润增长率 > -30%
  ✅ 自由现金流为正（金融/半导体豁免）
  ✅ 资产负债率 ≤ 行业上限

【第二关：打分门槛 —— 通过基本面筛选后计算】
  ✅ 基本面得分 ≥ 24/40
  ✅ 趋势动量得分 ≥ 14/20（原技术面折算：14/20 ≈ 28/40 等效门槛）
  ✅ 综合得分 ≥ 65/100
  ✅ 均线排列 = bullish（硬约束 H5，否则降级建议）

【第三关：筹码/资金面确认（任一加分项）】
  ✅ 量价筹码 buy_signals 非空（低位单峰+放量突破、双峰缩量回踩、V形反转）
  ✅ 或 资金面行为得分 ≥ 20/25
```

### 评级与建议映射

| 综合得分 | 评级 | 建议 |
|---------|------|------|
| ≥80分 | ⭐⭐⭐⭐⭐ 优秀 | ✅ 积极建仓：{行业}行业，四流派均衡得分，均线多头，筹码结构健康 |
| ≥70分 | ⭐⭐⭐⭐ 良好 | ✅ 积极建仓：{行业}行业，基本面优秀，趋势/筹码配合，可逢低布局 |
| ≥60分 | ⭐⭐⭐ 中性 | ⚠️ 谨慎关注：{行业}行业，基本面良好，{等待筹码密集/等待趋势确立} |
| ≥50分 | ⭐⭐ 偏弱 | 🔍 观察为主：{行业}行业，基本面中性，均线非bullish，观察为主 |
| <50分 | ⭐ 较差 | ⛔ 回避：{行业}行业，基本面或资金面偏弱，不建议参与 |

> **量价筹码信号提示**：建议文案末尾会追加买入/卖出信号摘要（如"📍 附加筹码信号：低位单峰密集+放量突破"或"⚠️ 警示：高位单峰密集+底部筹码消失"）。

### 卖出信号（任一触发）

```
⛔ 止盈：涨幅达 15%-20% → 分批减仓
⛔ 止损：跌破 MA20 且放量（成交量 > 5日均量 × 1.2）→ 立即止损
⛔ 趋势消退：所属行业指数跌破10日均线 → 被动减仓
⛔ 筹码派发出货：量价筹码 sell_signals 包含 S1/S2/S3（高位单峰+底部消失/筹码发散滞涨/上峰不移）
```

### 仓位建议（凯利公式）

```
建议仓位 = f * 挂钩资金比例

f = (p * b - q) / b

p = 历史胜率（近20次同类信号盈利次数 / 20）
q = 1 - p
b = 赔率（平均盈利 / 平均亏损）

约束：单票仓位上限 30%，下限 10%
```

## 执行步骤

```
Step 1: 接收 data-collection 产出的股票池（含 industry_level2 标签）

Step 2: 获取实时行情 + 构建 CH-4 全市场快照 + 资金面增强数据
  ├─ 批量获取实时行情（PE/PB/换手率/价格）
  ├─ build_universe_snapshot() → 构建全市场DataFrame
  ├─ filter_shell_stocks() → 剔除市值<30%分位的壳股
  ├─ fetch_batch_northbound() → 批量获取北向资金数据（阶段2，可选）
  ├─ fetch_batch_dragon_tiger() → 批量获取龙虎榜数据（阶段2，可选）
  └─ 缓存 universe_snapshot + northbound_data + dragon_tiger_data

Step 3: 基本面筛选（含 CH-4 壳价值过滤）
  ├─ 逐股票检查 ST/壳价值/ROE/利润增长/现金流/负债率
  ├─ 行业自适应阈值匹配
  └─ 通过 → 进入四流派打分；不通过 → 淘汰

Step 4: 四流派打分 + CH-4 因子暴露 + 量价筹码信号
  ├─ 基本面(40分)：ROE(10) + 营收增速(10) + 自由现金流(8) + 价值因子EP(7) + 股息率(5)
  ├─ 趋势动量(20分)：均线多头排列(8) + 趋势动量含反转(6) + 波动率ATR(3) + 行业热度(3)
  ├─ 量价筹码(15分)：筹码集中度(5) + 量价配合(5) + 支撑阻力(5) + buy_signals + sell_signals
  ├─ 资金面行为(25分)：基础20分×1.25（主力吸筹7.5+资金合力6.25+筹码健康6.25+行为锚定5）
  ├─ 资金面增强：北向资金(+2) + 龙虎榜(+2)（叠加在25分之上）
  └─ CH-4因子：compute_factor_exposure() → 四因子 z-score 暴露

Step 5: 综合打分融合
  ├─ traditional_total = 基本面(40) + 趋势动量(20) + 量价筹码(15) + 资金面行为(25)
  ├─ ch4_scaled = clip(50 + composite_score × 20, 0, 100)
  └─ total_score = 0.6 × traditional_total + 0.4 × ch4_scaled

Step 6: 排序 → 取 Top N（默认10只）

Step 7: 生成输出
  ├─ 每只股票输出：总得分 + 基本面得分 + 趋势动量得分 + 量价筹码得分 + 资金面行为得分 + CH-4因子暴露 + 各项小分明细
  ├─ 量价筹码买卖信号摘要（buy_signals / sell_signals）
  ├─ 评级与建议（追加筹码信号摘要）
  └─ JSON 格式（供 app.py 前端展示）

Step 8: （可选）生成个股分析报告
  ├─ 调用 stock_analyzer/ai_stock_analyzer.py
  ├─ 输出：估值区间、SWOT、买卖建议（含筹码信号）、凯利仓位
  └─ 报告格式：Markdown
```

## 注意事项

1. **行业阈值不可遗漏**：忘记走行业自适应 = 违反硬约束 H1，银行/半导体会被误杀。
2. **基本面是唯一筛选门槛**：技术面因子（均线/尾盘/量能/换手率）不再作为入围条件，仅用于打分排序。
3. **均线 bullish 不可绕过**：即使综合得分很高，均线排列非 bullish 也只能标记"观察"，不能给买入建议（硬约束 H5）。
4. **凯利仓位有上下限**：计算结果超出 10%-30% 范围时，自动截断到边界值。
5. **错误日志**：单只股票分析异常时会打印错误日志，不会中断整体选股流程。
6. **资金面权重映射**：资金面基础20分通过 ×1.25 线性缩放到方案A要求的25分。仓位关联规则阈值也同步×1.25（原≥16分 → 新≥20分）。
7. **量价筹码数据源**：优先使用 akshare `stock_cyq_em()` 接口获取东方财富筹码分布；接口失败时自动回退到换手率衰减模型自行计算（120日K线 + 半衰期60日）。
8. **筹码密集峰识别阈值**：单峰要求主峰筹码浓度≥25%；双峰要求次峰≥8%；峰位按价格0-33%/33-66%/66-100%划分为low/mid/high。
9. **筹码买卖信号判定严格遵循用户逻辑**：
   - B1低位单峰突破：CR10<15% + 单峰/low + 量比>1.8突破MA20
   - B2双峰缩量回踩：双峰 + 缩量回踩 + 底部筹码>50%
   - S1高位单峰派发：单峰/high + 底部筹码<30%
   - S3上峰不移：价跌破峰下沿 + 上方套牢盘>40%
10. **CH-4 壳价值过滤必须基于横截面分位（硬约束 H7）**：禁止用固定市值阈值（如"市值<50亿"）替代"市值<全市场30%分位"，否则违反论文方法论，规模因子会被壳价值污染。
11. **CH-4 价值因子用 EP 而非 BP**：论文实证表明中国市场 EP 完全吸收 B/P 的解释力。禁止将价值因子改回 B/P（账面市值比），否则会损失约17%的年化 alpha。
12. **CH-4 因子融合有回退机制**：当 `universe_snapshot` 构建失败、样本数<50 或 `enable_ch4_factor=False` 时，系统自动回退到纯传统打分，保证可用性。回退时 `ch4_factors` 字段为空字典。
13. **CH-4 全市场快照需缓存**：每次 `run_screening` 都会重建快照，耗时约3-5分钟。生产环境应在 `pipeline.py` 中每日构建一次并缓存。
14. **异常换手率窗口固定60日**：PMG 情绪因子的异常换手率计算窗口为过去60个交易日，禁止随意调整窗口长度，否则会破坏因子的可比性。
15. **阶段2 EP 计算优先级**：EP 因子优先使用"扣非净利润/(上月末收盘价×总股本)"严格论文公式，数据不可用时自动回退到 1/PE。回退行为已测试验证。
16. **北向/龙虎榜数据为可选增强**：`enable_capital_enhancement` 配置控制是否获取北向和龙虎榜数据。API 调用失败时自动降级，不影响基础评分。
17. **北向资金/龙虎榜数据量限制**：为避免触发东方财富API限流，批量获取限制在前200只股票。资金面基础评分不依赖这些数据。
18. **资金面卖出信号优先**：当北向单日净卖出≥1亿或龙虎榜净流出时，仓位建议直接降级为"回避"，优先级高于所有买入信号。
19. **量价筹码与资金面不重复计分**：流派2（量价筹码）的"筹码集中度/支撑阻力"与流派4（资金面行为）的"筹码健康度"计算数据源同源但逻辑独立：前者侧重筹码分布的静态结构（峰形/CR10/支撑位），后者侧重动态行为（锁仓/出货/一家独大）。两者分别打分无重复计算。
