## 🎯 核心知识点概览

### 一、20日线（MA20）

**定义**：过去20个交易日收盘价的平均值连成的线，代表市场的"平均持股成本线"。

**三大功能**：
1. **判断趋势**：向上=上升趋势，向下=下降趋势
2. **支撑压力**：上升趋势中是支撑（地板），下降趋势中是压力（天花板）
3. **多空信号**：突破=转强信号，跌破=转弱信号

**关键提醒**：它是滞后指标，不能预测未来，只能描述现状。

---

### 二、支撑与压力位的心理本质

| 类型 | 核心心理 | 市场表现 |
|------|---------|---------|
| **支撑（地板）** | 盈利者惜售，不愿卖出 | 卖盘枯竭，股价容易反弹 |
| **压力（天花板）** | 套牢者急于解套 | 卖盘涌出，股价难以突破 |

---

### 三、做空机制

**做多 vs 做空**：
- **做多**：先买后卖，盼涨，低买高卖
- **做空**：先卖后买，盼跌，高卖低买

**做空风险**：
- 亏损理论上无限
- 逼空风险极高
- 需要支付利息成本

---

### 四、实战操作原则

#### 下降趋势中（股价<20日线）
```
股价向上接近20日线
→ 套牢盘解套出逃
→ 卖出/减仓（不要买入！）
```

#### 上升趋势中（股价>20日线）
```
股价向下接近20日线
→ 盈利者惜售，场外资金接盘
→ 等待企稳信号后买入（不是无脑买！）
```

#### 企稳信号确认
1. **K线形态**：锤子线、金针探底
2. **成交量**：触碰时缩量，反弹时放量
3. **次日确认**：不创新低，小幅上涨

## 💡 投资心得

### 技术分析的正确定位
1. **辅助工具**：技术分析是投资的辅助工具，而非决策的绝对依据
2. **心理反映**：技术指标本质上是市场参与者心理和行为的反映
3. **自我实现**：当越来越多人相信并按此操作时，会形成"自我实现"的循环

### 基本面 vs 技术面
> 对于基本面仍在亏损、有破产风险的公司，**基本面的变化（如能否盈利、融资进展）远比K线图上的均线更重要**。如果基本面恶化，任何技术支撑位都可能被轻易击穿。

### 核心投资原则
1. **不要预测，要应对**：根据市场变化调整操作，而非预测市场
2. **严格止损**：控制风险永远是第一要务
3. **分散投资**：不要把鸡蛋放在一个篮子里
4. **长期主义**：投资是一场马拉松，不是百米冲刺
5. **控制情绪**：贪婪和恐惧是投资最大的敌人
