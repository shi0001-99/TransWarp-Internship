## 视频74：Kmeans算法常用操作（第十章：聚类算法实验分析 1）

### 知识点
- **Sklearn中的KMeans**：
  ```python
  from sklearn.cluster import KMeans
  kmeans = KMeans(
      n_clusters=8,
      init='k-means++',      # 初始化方法
      n_init=10,              # 重复运行次数
      max_iter=300,           # 最大迭代次数
      tol=0.0001,             # 收敛阈值
      random_state=0
  )
  ```
- **常用属性**：
  - `cluster_centers_`：簇中心
  - `labels_`：每个样本的簇标签
  - `inertia_`：样本到最近簇中心距离之和

## 视频77：不稳定结果（4）

### 知识点
- **K-Means不稳定性原因**：
  - 随机初始化导致不同结果
  - 数据分布不均匀
  - 簇的形状非凸
- **解决方案**：
  - 多次运行取平均
  - 使用K-Means++初始化
  - 增加`n_init`参数
  - 使用Mini-Batch K-Means加速

## 视频78：评估指标-Inertia（5）

### 知识点
- **Inertia（簇内平方和）**：
  - 公式：$\text{Inertia} = \sum_{k=1}^{K} \sum_{x \in C_k} |x - \mu_k|^2$
  - 值越小，簇内相似度越高
  - 随K增大单调递减
- **肘部法则**：
  1. 计算K=1到K=n的Inertia
  2. 绘制Inertia随K变化曲线
  3. 选择曲线拐点作为最优K

## 视频79：如何找到合适的K值（6）

### 知识点
- **K值选择方法**：
  - **肘部法则**：Inertia曲线的拐点
  - **轮廓系数法**：选择轮廓系数最大的K
  - **Gap统计量**：比较聚类结果与随机分布的差异
- **轮廓系数（Silhouette Score）**：
  - $s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}$
  - $a(i)$：样本$i$与同簇其他样本的平均距离
  - $b(i)$：样本$i$与最近邻簇的平均距离
  - 取值范围[-1, 1]，越大越好

## 视频80：轮廓系数的作用（7）

### 知识点
- **轮廓系数解读**：
  - $\approx 1$：样本与本簇相似度高，与其他簇相似度低
  - $\approx 0$：样本位于簇边界
  - $\approx -1$：样本可能被错误分类
- **整体轮廓系数**：所有样本轮廓系数的平均值
- **可视化**：
  - 轮廓系数图（Silhouette Plot）
  - 不同K值的轮廓系数对比

## 视频81：Kmeans算法存在的问题（8）

### 知识点
- **K-Means的局限性**：
  - 需预设K值
  - 对初始中心敏感
  - 难以处理非凸形簇
  - 对异常值敏感
  - 难以处理不同大小和密度的簇
- **改进算法**：
  - K-Medoids：使用中心点而非均值
  - Fuzzy C-Means：软聚类，每个样本可属于多个簇
  - Mini-Batch K-Means：使用小批量加速

## 视频82：应用实例-图像分割（9）

### 知识点
- **图像分割原理**：
  - 将图像像素作为数据点
  - 使用颜色特征（RGB）或纹理特征进行聚类
  - 不同簇代表不同区域
- **代码实现**：
  ```python
  from PIL import Image
  img = Image.open('image.jpg')
  img_data = np.array(img).reshape(-1, 3)  # (H*W, 3)
  kmeans = KMeans(n_clusters=5)
  kmeans.fit(img_data)
  segmented = kmeans.cluster_centers_[kmeans.labels_].reshape(img.shape)
  ```
- **效果对比**：不同K值的分割结果

## 视频83：半监督学习（10）

### 知识点
- **半监督学习**：
  - 少量有标签数据 + 大量无标签数据
  - 利用无标签数据提升模型性能
- **自训练（Self-Training）**：
  1. 用有标签数据训练模型
  2. 对无标签数据预测
  3. 将高置信度的预测加入训练集
  4. 重复直至收敛
- **K-Means在半监督中的应用**：
  - 先聚类，再用聚类结果辅助分类
