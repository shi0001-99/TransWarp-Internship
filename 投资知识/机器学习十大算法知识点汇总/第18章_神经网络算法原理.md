## 视频139：得分函数（5）

### 知识点
- **线性分类器得分函数**：
  - $f(x) = W x + b$
  - $x$：输入特征向量
  - $W$：权重矩阵
  - $b$：偏置项
  - 输出：每个类别的得分
- **多分类得分**：
  - C个类别 → C维输出
  - 每个类别一个得分
  - 取最高分作为预测类别
- **问题**：线性分类器表达能力有限

## 视频140：损失函数的作用（6）

### 知识点
- **损失函数（Loss Function）**：
  - 衡量模型预测值与真实值的差异
  - 指导参数更新方向
- **常用损失函数**：
  - 0-1损失：错误数
  - Hinge损失（SVM）
  - 交叉熵损失（分类）
  - MSE损失（回归）
- **多分类交叉熵损失**：
  - $L = -\sum y_i \log(\hat{y}_i)$
  - $y_i$：真实标签（one-hot）
  - $\hat{y}_i$：预测概率

## 视频141：前向传播整体流程（7）

### 知识点
- **神经网络结构**：
  - 输入层 → 隐藏层 → 输出层
  - 每层由多个神经元组成
- **前向传播（Forward Propagation）**：
  1. 输入 $x$
  2. 线性变换 $z = W x + b$
  3. 激活函数 $a = \sigma(z)$
  4. 重复直至输出层
- **前向传播公式**：
  - $a^{(1)} = \sigma(W^{(1)} x + b^{(1)})$
  - $a^{(2)} = \sigma(W^{(2)} a^{(1)} + b^{(2)})$
  - $\hat{y} = \text{softmax}(W^{(L)} a^{(L-1)} + b^{(L)})$

## 视频142：反向传播计算方法（8）

### 知识点
- **反向传播（Backpropagation）**：
  - 从输出层向输入层逐层计算梯度
  - 使用链式法则
- **计算步骤**：
  1. 计算输出层误差 $\delta^{(L)} = \hat{y} - y$
  2. 反传误差 $\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$
  3. 计算梯度 $\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} a^{(l-1)T}$
  4. 更新参数 $W^{(l)} -= \alpha \frac{\partial L}{\partial W^{(l)}}$
- **链式法则应用**：
  - $\frac{\partial L}{\partial W} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial W}$

## 视频144：神经网络架构细节（10）

### 知识点
- **各层类型**：
  - 全连接层（FC/Dense）
  - 卷积层（Conv）
  - 池化层（Pooling）
  - 激活层（ReLU、Sigmoid、Tanh）
  - Dropout层
  - 归一化层（BatchNorm）
- **激活函数对比**：

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 0-1范围，易梯度消失 |
| Tanh | $\tanh(x)$ | -1-1范围，零均值 |
| ReLU | $\max(0, x)$ | 计算快，稀疏激活 |
| LeakyReLU | $\max(\alpha x, x)$ | 解决ReLU死亡问题 |

## 视频146：正则化与激活函数（12）

### 知识点
- **正则化方法**：
  - L1/L2正则化：添加权重惩罚项
  - Dropout：随机丢弃部分神经元
  - 早停（Early Stopping）
  - 数据增强
  - 权重衰减
- **Dropout原理**：
  - 训练时：随机丢弃p%的神经元
  - 推理时：使用所有神经元，权重缩放
  - 类似于集成学习
- **激活函数选择**：
  - 隐藏层：ReLU（默认选择）
  - 输出层分类：Sigmoid/Softmax
  - 输出层回归：线性/恒等

## 视频147：神经网络过拟合解决方法（13）

### 知识点
- **过拟合诊断**：
  - 训练误差远低于验证误差
  - 验证曲线出现分离
- **解决过拟合的方法**：
  1. 增加训练数据
  2. 使用数据增强
  3. 添加正则化（L1/L2）
  4. 使用Dropout
  5. 早停策略
  6. 减小网络规模
  7. 权重初始化
- **正则化对比实验**：
  - 无正则化 vs L2 vs Dropout vs 早停
  - 观察验证曲线变化
