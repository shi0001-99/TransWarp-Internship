## 视频94：递归生成树节点（2）

### 知识点
- **树节点结构**：
  ```python
  class TreeNode:
      def __init__(self):
          self.feature = None       # 划分特征索引
          self.threshold = None     # 划分阈值
          self.left = None          # 左子树
          self.right = None         # 右子树
          self.value = None         # 叶节点预测值
          self.is_leaf = False      # 是否为叶节点
  ```
- **递归构建**：
  ```python
  def _build_tree(self, X, y, depth=0):
      # 终止条件
      if self._should_stop(y, depth):
          return self._create_leaf(y)
      
      # 寻找最佳划分
      feature, threshold = self._best_split(X, y)
      
      # 创建节点并递归
      node = TreeNode(feature, threshold)
      left_X, left_y, right_X, right_y = self._split(X, y, feature, threshold)
      node.left = self._build_tree(left_X, left_y, depth+1)
      node.right = self._build_tree(right_X, right_y, depth+1)
      return node
  ```

## 视频95：整体框架逻辑（3）

### 知识点
- **训练主流程**：
  1. 检查终止条件（所有样本同类/达到最大深度）
  2. 计算每个特征的信息增益
  3. 选择最佳划分特征和阈值
  4. 划分数据集
  5. 递归构建左右子树
  6. 返回根节点
- **预测流程**：
  1. 从根节点开始
  2. 根据特征判断走向
  3. 重复直至叶节点
  4. 返回叶节点预测值

## 视频96：熵值计算（4）

### 知识点
- **熵计算实现**：
  ```python
  def _compute_entropy(self, y):
      _, counts = np.unique(y, return_counts=True)
      probabilities = counts / len(y)
      entropy = -np.sum(probabilities * np.log2(probabilities + 1e-10))
      return entropy
  ```
- **Gini系数计算**：
  ```python
  def _compute_gini(self, y):
      _, counts = np.unique(y, return_counts=True)
      probabilities = counts / len(y)
      gini = 1 - np.sum(probabilities**2)
      return gini
  ```

## 视频97：数据集切分（5）

### 知识点
- **特征划分方式**：
  - 离散特征：按特征值划分（ID3/C4.5）
  - 连续特征：寻找最佳阈值进行二叉划分（CART）
- **连续特征划分实现**：
  ```python
  def _best_threshold(self, X_column, y):
      thresholds = np.unique(X_column)
      best_gain = -1
      best_threshold = None
      
      for threshold in thresholds:
          left_mask = X_column <= threshold
          right_mask = X_column > threshold
          
          # 计算信息增益
          gain = self._compute_gain(y, left_mask, right_mask)
          
          if gain > best_gain:
              best_gain = gain
              best_threshold = threshold
      
      return best_threshold, best_gain
  ```

## 视频98：完成树模型构建（6）

### 知识点
- **完整训练实现**：
  ```python
  def fit(self, X, y):
      self.tree = self._build_tree(X, y)
      
  def predict(self, X):
      return np.array([self._traverse_tree(x, self.tree) for x in X])
      
  def _traverse_tree(self, x, node):
      if node.is_leaf:
          return node.value
      if x[node.feature] <= node.threshold:
          return self._traverse_tree(x, node.left)
      return self._traverse_tree(x, node.right)
  ```
- **终止条件实现**：
  - `len(set(y)) == 1`：所有样本同类
  - `depth >= self.max_depth`：达到最大深度
  - `len(y) < self.min_samples_split`：样本数不足
