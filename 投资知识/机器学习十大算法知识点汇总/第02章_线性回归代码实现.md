## 视频12：实现梯度下降优化模块（3）

### 知识点
- **梯度下降核心代码逻辑**：
  ```python
  for i in range(n_iterations):
      y_pred = np.dot(X, W) + b      # 前向传播
      error = y_pred - y              # 计算误差
      dW = (1/m) * np.dot(X.T, error) + (lambda/m) * W  # 权重梯度
      db = (1/m) * np.sum(error)      # 偏置梯度
      W -= learning_rate * dW         # 更新权重
      b -= learning_rate * db         # 更新偏置
      loss = np.mean((y_pred - y)**2) # 计算损失
  ```
- **学习率衰减**：随迭代次数逐渐减小学习率
- **梯度裁剪**：防止梯度爆炸

## 视频13：损失与预测模块（4）

### 知识点
- **损失函数实现**：
  - MSE（均方误差）：$J = \frac{1}{m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2$
  - MAE（平均绝对误差）：$J = \frac{1}{m} \sum_{i=1}^{m} |y_i - \hat{y}_i|$
- **预测函数**：$\hat{y} = X \cdot W + b$
- **损失记录**：每轮迭代记录损失值，用于可视化训练过程

## 视频14：数据与标签定义（5）

### 知识点
- **数据结构约定**：
  - $X$：形状为 `(m, n)` 的特征矩阵，$m$为样本数，$n$为特征数
  - $y$：形状为 `(m, 1)` 的标签向量
- **数据类型转换**：确保数据为float类型
- **数据示例**：
  ```python
  # 房价预测数据
  X = np.array([[面积, 房间数, 楼层], ...])
  y = np.array([房价, ...])
  ```

## 视频15：训练线性回归模型（6）

### 知识点
- **训练流程**：
  1. 前向传播计算预测值
  2. 计算损失函数
  3. 反向传播计算梯度
  4. 更新参数
  5. 重复直至收敛
- **损失收敛判断**：
  - 连续多轮损失变化小于阈值
  - 达到最大迭代次数
- **训练过程监控**：记录每轮损失值，绘制损失曲线

---

## 视频16：得到线性回归方程（7）

### 知识点
- **模型输出**：$y = w_1 x_1 + w_2 x_2 + ... + w_n x_n + b$
- **权重含义**：每个特征的权重表示该特征对预测结果的贡献
- **模型解释**：
  - 权重为正：特征增加 → 预测值增加
  - 权重为负：特征增加 → 预测值减少
- **特征重要性排序**：根据权重绝对值大小排序

## 视频18：多特征回归模型（9）

### 知识点
- **单特征 vs 多特征**：
  - 单特征：$y = wx + b$
  - 多特征：$y = w_1 x_1 + w_2 x_2 + ... + w_n x_n + b$
- **多特征矩阵运算**：$\hat{Y} = X W + b$
- **特征相关性处理**：
  - 高相关特征会导致权重不稳定
  - 可以通过特征选择或PCA处理

---

## 视频19：非线性回归（10）

### 知识点
- **多项式回归**：$y = w_0 + w_1 x + w_2 x^2 + ... + w_n x^n$
- **特征变换**：将原始特征转换为多项式特征
  ```python
  # 添加多项式特征
  X_poly = np.column_stack([X, X**2, X**3])
  ```
- **过拟合风险**：多项式阶数过高容易过拟合
- **正则化**：加入L1/L2正则化项防止过拟合
