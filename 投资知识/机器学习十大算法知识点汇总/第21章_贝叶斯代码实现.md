## 视频169：分类别统计词频（4）

### 知识点
- **按类别统计词频**：
  ```python
  def _count_words_by_class(self, X, y):
      # 按类别分组
      class_word_counts = {}
      for class_label in np.unique(y):
          class_mask = (y == class_label)
          class_texts = X[class_mask]
          
          # 统计该类别每个词的出现次数
          word_counts = class_texts.sum(axis=0)
          class_word_counts[class_label] = word_counts
      
      return class_word_counts
  ```
- **先验概率计算**：
  - $P(\text{类别}) = \frac{\text{该类别样本数}}{\text{总样本数}}$

## 视频170：贝叶斯公式对数变换（5）

### 知识点
- **对数变换的必要性**：
  - 避免概率连乘导致下溢
  - 简化计算（乘法变加法）
- **对数贝叶斯公式**：
  - $\log P(\text{类}|\text{文档}) \propto \log P(\text{文档}|\text{类}) + \log P(\text{类})$
  - $\log P(\text{文档}|\text{类}) = \sum \log P(\text{词}|\text{类})$
- **拉普拉斯平滑**：
  - 解决零概率问题
  - $P(w|c) = \frac{\text{count}(w, c) + \alpha}{\text{total}(c) + \alpha |V|}$
  - $\alpha$：平滑参数（通常为1）
- **代码实现**：
  ```python
  log_probs = np.log((word_counts + self.alpha) / 
                     (total_words + self.alpha * len(vocab)))
  ```

## 视频171：完成预测模块（6）

### 知识点
- **预测流程**：
  ```python
  def predict(self, X):
      predictions = []
      for text_vector in X:
          posteriors = []
          
          for class_label in self.classes:
              # 计算对数先验
              log_prior = np.log(self.priors[class_label])
              
              # 计算对数似然
              log_likelihood = np.sum(text_vector * self.log_probs[class_label])
              
              # 后验（对数）
              posterior = log_prior + log_likelihood
              posteriors.append((class_label, posterior))
          
          # 选择后验概率最大的类别
          predictions.append(max(posteriors, key=lambda x: x[1])[0])
      
      return np.array(predictions)
  ```
