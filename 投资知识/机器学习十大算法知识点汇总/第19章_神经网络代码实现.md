## 视频149：参数初始化操作（2）

### 知识点
- **权重初始化方法**：
  - 全零初始化：不推荐，对称性问题
  - 随机小值：基本方法
  - Xavier初始化：适合Sigmoid/Tanh
    - $W \sim U[-\sqrt{6/(n_{in}+n_{out})}, \sqrt{6/(n_{in}+n_{out})}]$
  - He初始化：适合ReLU
    - $W \sim N(0, \sqrt{2/n_{in}})$
- **代码实现**：
  ```python
  def _initialize_weights(self):
      self.weights = []
      self.biases = []
      for i in range(len(self.layer_sizes) - 1):
          # He初始化
          W = np.random.randn(self.layer_sizes[i], self.layer_sizes[i+1]) * \
              np.sqrt(2 / self.layer_sizes[i])
          b = np.zeros((1, self.layer_sizes[i+1]))
          self.weights.append(W)
          self.biases.append(b)
  ```

## 视频152：完成前向传播模块（5）

### 知识点
- **前向传播完整实现**：
  ```python
  def _forward(self, X):
      self.a = [X]  # 存储每层激活值
      self.z = []   # 存储每层线性变换值
      
      for i in range(len(self.weights)):
          z = np.dot(self.a[i], self.weights[i]) + self.biases[i]
          self.z.append(z)
          
          if i == len(self.weights) - 1:
              # 输出层
              if self.task == 'binary':
                  a = self._sigmoid(z)
              elif self.task == 'multiclass':
                  a = self._softmax(z)
              else:
                  a = z  # 线性输出
          else:
              # 隐藏层
              a = self._relu(z)  # 或其他激活函数
          
          self.a.append(a)
      
      return self.a[-1]
  ```
- **激活函数实现**：
  ```python
  def _relu(self, z):
      return np.maximum(0, z)
      
  def _sigmoid(self, z):
      return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
      
  def _softmax(self, z):
      exp_z = np.exp(z - np.max(z, axis=1, keepdims=True))
      return exp_z / np.sum(exp_z, axis=1, keepdims=True)
  ```

## 视频153：损失函数定义（6）

### 知识点
- **损失函数实现**：
  ```python
  def _compute_loss(self, y_pred, y_true):
      if self.task == 'binary':
          # 二分类交叉熵
          loss = -np.mean(y_true * np.log(y_pred + 1e-10) + 
                         (1 - y_true) * np.log(1 - y_pred + 1e-10))
      elif self.task == 'multiclass':
          # 多分类交叉熵
          loss = -np.mean(np.sum(y_true * np.log(y_pred + 1e-10), axis=1))
      else:
          # MSE
          loss = np.mean((y_pred - y_true) ** 2)
      return loss
  ```

## 视频154：准备反向传播迭代（7）

### 知识点
- **反向传播初始化**：
  - 从输出层开始计算误差
  - 逐层向前传播
- **需要保存的中间结果**：
  - 每层的激活值 $a$
  - 每层的线性变换值 $z$
  - 每层的权重 $W$
- **反向传播伪代码**：
  ```python
  def _backward(self, y_true):
      m = y_true.shape[0]
      gradients = []
      
      # 输出层误差
      delta = self.a[-1] - y_true  # 交叉熵+softmax的简化
      
      # 从后往前逐层计算
      for i in reversed(range(len(self.weights))):
          dW = np.dot(self.a[i].T, delta) / m
          db = np.sum(delta, axis=0) / m
          gradients.insert(0, [dW, db])
          
          if i > 0:
              delta = np.dot(delta, self.weights[i].T)
              delta = delta * (self.z[i] > 0)  # ReLU的导数
      
      return gradients
  ```

## 视频155：差异项计算（8）

### 知识点
- **各层误差项计算**：
  - 输出层（交叉熵+Softmax）：
    - $\delta^{(L)} = a^{(L)} - y$
  - 输出层（Sigmoid+交叉熵）：
    - $\delta^{(L)} = a^{(L)} - y$
  - 隐藏层（ReLU）：
    - $\delta^{(l)} = (\delta^{(l+1)} W^{(l+1)T}) \odot (z^{(l)} > 0)$
  - 隐藏层（Sigmoid）：
    - $\delta^{(l)} = (\delta^{(l+1)} W^{(l+1)T}) \odot \sigma(z^{(l)}) \odot (1 - \sigma(z^{(l)}))$
- **矩阵维度检查**：每一步都要验证维度匹配

## 视频157：完成全部迭代更新模块（10）

### 知识点
- **训练主循环**：
  ```python
  def fit(self, X, y, epochs=1000, learning_rate=0.01):
      losses = []
      
      for epoch in range(epochs):
          # 前向传播
          y_pred = self._forward(X)
          
          # 计算损失
          loss = self._compute_loss(y_pred, y)
          losses.append(loss)
          
          # 反向传播
          grads = self._backward(y)
          
          # 更新参数
          for i in range(len(self.weights)):
              self.weights[i] -= learning_rate * grads[i]['dW']
              self.biases[i] -= learning_rate * grads[i]['db']
          
          # 打印进度
          if (epoch + 1) % 100 == 0:
              print(f'Epoch {epoch+1}/{epochs}, Loss: {loss:.4f}')
      
      return losses
  ```

## 视频159：算法代码错误修正（12）

### 知识点
- **常见Bug**：
  1. 维度不匹配：矩阵乘法维度错误
  2. 激活函数导数错误：忘记乘以导数
  3. 损失函数计算错误：数值溢出
