## 视频178：Apriori算法整体流程（第二十三章：关联规则代码实现 1）

### 知识点
- **Apriori算法核心思想**：
  - 频繁项集的任何子集也是频繁的
  - 先找小项集，再逐步扩展
- **算法步骤**：
  1. 扫描数据库，统计每个单项的支持度
  2. 筛选满足最小支持度的单项集
  3. 由频繁k项集生成候选(k+1)项集
  4. 扫描数据库验证候选项集
  5. 重复直至无法生成新项集
- **伪代码**：
  ```python
  def apriori(transactions, min_support):
      items = get_all_items(transactions)
      frequent_1 = {item: support(item) for item in items 
                    if support(item) >= min_support}
      frequent_sets = [frequent_1]
      
      k = 2
      while True:
          candidates = generate_candidates(frequent_sets[k-2], k)
          frequent_k = {c: support(c) for c in candidates 
                        if support(c) >= min_support}
          if not frequent_k:
              break
          frequent_sets.append(frequent_k)
          k += 1
      
      return frequent_sets
  ```

## 视频180：扫描模块（3）

### 知识点
- **统计项集支持度**：
  ```python
  def compute_support(itemset, transactions):
      count = 0
      for transaction in transactions:
          if itemset.issubset(transaction):
              count += 1
      return count / len(transactions)
  ```
- **优化技巧**：
  - 使用集合（set）加速子集判断
  - 一次扫描统计所有候选项集
  - 位图存储事务数据

## 视频181：拼接模块（4）

### 知识点
- **生成候选项集（连接步骤）**：
  ```python
  def generate_candidates(frequent_itemsets, k):
      candidates = set()
      items = list(frequent_itemsets)
      
      for i in range(len(items)):
          for j in range(i + 1, len(items)):
              # 合并两个频繁(k-1)项集
              union = items[i] | items[j]
              if len(union) == k:
                  candidates.add(frozenset(union))
      
      return candidates
  ```
- **剪枝步骤**：
  - 检查候选项集的所有(k-1)子集是否都是频繁的
  - 若非频繁，则剔除该候选

## 视频182：挖掘频繁项集（5）

### 知识点
- **完整频繁项集挖掘**：
  ```python
  def find_frequent_itemsets(transactions, min_support):
      # 第一步：找频繁1项集
      item_counts = {}
      for transaction in transactions:
          for item in transaction:
              item_counts[item] = item_counts.get(item, 0) + 1
      
      n = len(transactions)
      frequent_1 = {frozenset([item]): count/n 
                     for item, count in item_counts.items() 
                     if count/n >= min_support}
      
      # 后续步骤：找频繁2+项集
      all_frequent = dict(frequent_1)
      current_frequent = list(frequent_1.keys())
      k = 2
      
      while current_frequent:
          candidates = generate_candidates(current_frequent, k)
          frequent_k = {}
          for candidate in candidates:
              support = compute_support(candidate, transactions)
              if support >= min_support:
                  frequent_k[candidate] = support
          
          all_frequent.update(frequent_k)
          current_frequent = list(frequent_k.keys())
          k += 1
      
      return all_frequent
  ```

## 视频183：规则生成模块（6）

### 知识点
- **由频繁项集生成关联规则**：
  ```python
  def generate_association_rules(frequent_itemsets, min_confidence):
      rules = []
      
      for itemset, support in frequent_itemsets.items():
          # 生成所有可能的分割
          for i in range(1, len(itemset)):
              antecedent = frozenset(list(itemset)[:i])
              consequent = itemset - antecedent
              
              # 计算置信度
              confidence = support / frequent_itemsets[antecedent]
              
              if confidence >= min_confidence:
                  # 计算提升度
                  lift = confidence / frequent_itemsets[consequent]
                  rules.append({
                      'antecedent': antecedent,
                      'consequent': consequent,
                      'support': support,
                      'confidence': confidence,
                      'lift': lift
                  })
      
      return rules
  ```

## 视频184：完成全部算法流程（7）

### 知识点
- **完整Apriori实现**：
  ```python
  class Apriori:
      def __init__(self, min_support=0.5, min_confidence=0.5):
          self.min_support = min_support
          self.min_confidence = min_confidence
          self.frequent_itemsets = {}
          self.rules = []
      
      def fit(self, transactions):
          # 1. 挖掘频繁项集
          self.frequent_itemsets = find_frequent_itemsets(
              transactions, self.min_support)
          # 2. 生成关联规则
          self.rules = generate_association_rules(
              self.frequent_itemsets, self.min_confidence)
          return self
      
      def get_rules(self):
          return sorted(self.rules, key=lambda x: x['confidence'], reverse=True)
  ```
