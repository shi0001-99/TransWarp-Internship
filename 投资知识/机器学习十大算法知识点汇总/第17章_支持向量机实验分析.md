  from sklearn.svm import SVC

## 视频131：决策边界可视化展示（2）

### 知识点
- **线性SVM决策边界**：
  - 最大间隔超平面
  - 支持向量标记
  - 间隔边界（虚线）
- **可视化代码**：
  ```python
  def plot_svm_boundary(X, y, svm):
      # 创建网格
      x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
      y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
      xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100),
                           np.linspace(y_min, y_max, 100))
      
      # 预测
      Z = svm.decision_function(np.c_[xx.ravel(), yy.ravel()])
      Z = Z.reshape(xx.shape)
      
      # 绘制
      plt.contourf(xx, yy, Z, levels=[-1, 0, 1], alpha=0.3)
      plt.scatter(X[:, 0], X[:, 1], c=y)
      
      # 标记支持向量
      plt.scatter(svm.support_vectors_[:, 0], 
                  svm.support_vectors_[:, 1],
                  s=100, facecolors='none', edgecolors='red')
  ```

## 视频132：软间隔的作用（3）

### 知识点
- **C参数实验**：
  - C=0.01：间隔大，允许更多错误
  - C=1：平衡间隔和准确率
  - C=100：间隔小，分类更准确
- **不同C值的决策边界对比**：
  - 小C：平滑的决策边界，可能欠拟合
  - 大C：复杂的决策边界，可能过拟合
- **C参数选择**：
  - 通过验证曲线或交叉验证选择
  - 类别不平衡时可调整类权重

## 视频133：非线性SVM（4）

### 知识点
- **非线性问题**：
  - 线性SVM无法解决
  - 需要使用核函数
- **RBF核SVM**：
  ```python
  svm_rbf = SVC(kernel='rbf', C=1.0, gamma='scale')
  svm_rbf.fit(X_train, y_train)
  ```
- **不同核函数对比**：
  - 线性核：$K = x_i^T x_j$
  - 多项式核：$K = (x_i^T x_j)^d$
  - RBF核：$K = \exp(-\gamma\|x_i-x_j\|^2)$
  - Sigmoid核：$K = \tanh(\gamma x_i^T x_j)$

## 视频134：核函数的作用与效果（5）

### 知识点
- **核函数对比实验**：
  ```python
  kernels = ['linear', 'poly', 'rbf', 'sigmoid']
  for kernel in kernels:
      svm = SVC(kernel=kernel)
      svm.fit(X_train, y_train)
      print(f'{kernel}: {svm.score(X_test, y_test):.3f}')
  ```
- **$\gamma$参数的影响**：
  - $\gamma$小：决策边界平滑
  - $\gamma$大：决策边界复杂
  - `gamma='scale'` 或 `gamma='auto'` 自动调整
- **网格搜索调优**：
  ```python
  from sklearn.model_selection import GridSearchCV
  param_grid = {
      'C': [0.1, 1, 10, 100],
      'gamma': ['scale', 'auto', 0.1, 1, 10],
      'kernel': ['rbf', 'linear']
  }
  grid = GridSearchCV(SVC(), param_grid, cv=5)
  ```
- **多分类SVM**：
  - One-vs-Rest：每个类别一个分类器
  - One-vs-One：每两个类别一个分类器
