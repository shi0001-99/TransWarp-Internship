## 视频46：完成预测模块（3）

### 知识点
- **概率预测**：
  - 二分类：$P(y=1|x) = \sigma(w^T x + b)$
  - 多分类：$P(y=k|x) = \text{softmax}(W^T x + b)_k$
- **类别预测**：
  - 二分类：概率 > 0.5 判为正类
  - 多分类：选择最大概率对应的类别
- **决策边界可视化**：将特征空间划分为不同区域

## 视频47：优化目标定义（4）

### 知识点
- **交叉熵损失函数实现**：
  ```python
  def compute_loss(y_true, y_pred):
      m = len(y_true)
      loss = -1/m * np.sum(y_true * np.log(y_pred) + (1-y_true) * np.log(1-y_pred))
      return loss
  ```
- **数值稳定性处理**：
  - 防止$\log(0)$，使用 $\epsilon$ 平滑：`y_pred = np.clip(y_pred, 1e-10, 1-1e-10)`

## 视频48：迭代优化参数（5）

### 知识点
- **梯度下降参数更新**：
  ```python
  for i in range(n_iterations):
      y_pred = sigmoid(np.dot(X, W) + b)
      error = y_pred - y
      dW = (1/m) * np.dot(X.T, error)
      db = (1/m) * np.sum(error)
      W -= lr * dW
      b -= lr * db
  ```
- **损失记录与监控**：每轮迭代记录损失，判断收敛

## 视频49：梯度计算（6）

### 知识点
- **二分类梯度推导**：
  - 预测：$\hat{y} = \sigma(z)$，$z = w^T x + b$
  - 损失：$J = -[y \log \hat{y} + (1-y) \log(1-\hat{y})]$
  - 梯度：$\frac{dJ}{dz} = \hat{y} - y$
  - $\frac{dJ}{dw} = \frac{1}{m} \sum (\hat{y}_i - y_i) x_i$
- **多分类梯度**：与二分类推导类似，使用Softmax
