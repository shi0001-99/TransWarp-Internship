# 第16章 支持向量机原理推导

> 对应视频：第121-129讲

## 视频121：支持向量机要解决的问题（第十六章：支持向量机原理推导 1）

### 知识点
- **支持向量机（SVM）**：
  - 由Cortes和Vapnik于1995年提出
  - 核心思想：找到最佳分类超平面
  - 目标：使分类间隔最大化
- **分类超平面**：$w^T x + b = 0$
- **分类规则**：
  - $w^T x + b > 0$ → 正类
  - $w^T x + b < 0$ → 负类
- **什么是"最佳"超平面**：
  - 到两类最近样本点的距离最大
  - 即最大间隔（Maximum Margin）

---

## 视频122：距离与数据定义（2）

### 知识点
- **点到超平面的距离**：
  - 距离公式：$d = \frac{|w^T x + b|}{\|w\|}$
- **几何间隔**：
  - 正类样本满足：$w^T x + b \geq 1$
  - 负类样本满足：$w^T x + b \leq -1$
  - 间隔宽度：$\frac{2}{\|w\|}$
- **支持向量（Support Vectors）**：
  - 距离超平面最近的样本点
  - 决定分类超平面的位置
- **硬间隔**：要求所有样本都正确分类且间隔最大

## 视频123：目标函数推导（3）

### 知识点
- **优化目标**：
  - 最大化几何间隔 $\frac{2}{\|w\|}$
  - 等价于最小化 $\|w\|^2$
- **约束条件**：
  - $y_i(w^T x_i + b) \geq 1, \forall i$
- **原始优化问题**：
  - $\min_{w,b} \frac{1}{2}\|w\|^2$
  - s.t. $y_i(w^T x_i + b) - 1 \geq 0$
- **这是一个凸二次规划问题**

---

## 视频124：拉格朗日乘子法求解（4）

### 知识点
- **拉格朗日函数构造**：
  - $L(w, b, \alpha) = \frac{1}{2}\|w\|^2 - \sum \alpha_i [y_i(w^T x_i + b) - 1]$
- **KKT条件**：
  - $\frac{\partial L}{\partial w} = w - \sum \alpha_i y_i x_i = 0$
  - $\frac{\partial L}{\partial b} = -\sum \alpha_i y_i = 0$
  - $\alpha_i \geq 0$
  - $\alpha_i [y_i(w^T x_i + b) - 1] = 0$
- **对偶问题**：
  - $\max_\alpha \sum \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$
  - s.t. $\sum \alpha_i y_i = 0, \alpha_i \geq 0$

---

## 视频125：化简最终目标函数（5）

### 知识点
- **对偶优化问题**：
  - $\max_\alpha W(\alpha) = \sum_{i=1}^{m} \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j K(x_i, x_j)$
  - s.t. $\sum \alpha_i y_i = 0, 0 \leq \alpha_i \leq C$（软间隔时）
- **核函数引入**：$K(x_i, x_j) = \phi(x_i)^T \phi(x_j)$
- **求解后**：
  - $w = \sum \alpha_i y_i x_i$
  - $b = y_j - w^T x_j$（对任意支持向量）
- **分类决策函数**：$f(x) = \text{sign}(\sum \alpha_i y_i K(x_i, x_j) + b)$

## 视频126：求解决策方程（6）

### 知识点
- **求解方法**：
  - SMO算法（Sequential Minimal Optimization）
  - 分解优化问题，每次只优化两个变量
- **SMO算法步骤**：
  1. 选择两个变量$\alpha_i, \alpha_j$
  2. 固定其他变量，优化这两个变量
  3. 重复直至收敛
- **Python实现**：
  - 可用cvxopt等优化库
  - 或使用简化的SMO实现

---

## 视频127：软间隔优化（7）

### 知识点
- **软间隔（Soft Margin）**：
  - 允许部分样本违反间隔约束
  - 引入松弛变量$\xi_i \geq 0$
  - 目标：$\min \frac{1}{2}\|w\|^2 + C \sum \xi_i$
- **约束条件**：
  - $y_i(w^T x_i + b) \geq 1 - \xi_i$
  - $\xi_i \geq 0$
- **C参数的含义**：
  - C大：强调分类正确，间隔小
  - C小：允许部分错误，间隔大
- **硬间隔 vs 软间隔**：
  - 硬间隔：线性可分，效果好
  - 软间隔：线性不可分，更鲁棒

## 视频128：核函数的作用（8）

### 知识点
- **核技巧（Kernel Trick）**：
  - 将输入映射到高维特征空间
  - 在高维空间中线性可分
  - 避免显式计算高维特征
- **常用核函数**：

| 核函数 | 公式 | 适用场景 |
|--------|------|---------|
| 线性核 | $K(x_i,x_j) = x_i^T x_j$ | 线性可分 |
| 多项式核 | $K = (x_i^T x_j + c)^d$ | 特征交叉 |
| RBF核 | $K = \exp(-\gamma\|x_i-x_j\|^2)$ | 通用，非线性 |
| Sigmoid核 | $K = \tanh(\gamma x_i^T x_j + c)$ | 神经网络 |

- **核函数选择建议**：
  - 特征多：先用线性核
  - 特征少：用RBF核
  - 不确定：尝试RBF核

---

## 视频129：知识点总结（9）

### 知识点
- **SVM核心要点**：
  1. 最大间隔原则：最大化分类间隔
  2. 硬间隔 vs 软间隔：是否允许分类错误
  3. 核技巧：处理非线性问题
  4. 支持向量：决定超平面的关键样本
  5. C参数：平衡间隔大小和分类准确率
  6. 核参数$\gamma$：控制RBF核的宽度
- **SVM优缺点**：
  - 优点：理论扎实，效果好，高维数据适用
  - 缺点：大数据集训练慢，调参复杂
