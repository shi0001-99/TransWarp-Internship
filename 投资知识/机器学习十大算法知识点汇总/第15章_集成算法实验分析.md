## 视频109：硬投票与软投票效果对比（2）

### 知识点
- **硬投票（Hard Voting）**：
  - 每个基学习器输出一个类别标签
  - 最终结果：多数投票
  - 代码：`VotingClassifier(voting='hard')`
- **软投票（Soft Voting）**：
  - 每个基学习器输出类别概率
  - 最终结果：概率加权平均
  - 代码：`VotingClassifier(voting='soft')`
- **实验对比**：软投票通常优于硬投票

## 视频114：AdaBoost算法概述（7）

### 知识点
- **AdaBoost（Adaptive Boosting）**：
  - 自适应调整样本权重
  - 被错误分类的样本权重增加
  - 被正确分类的样本权重降低
- **算法步骤**：
  1. 初始化样本权重 $w_i = 1/n$
  2. 训练弱学习器
  3. 计算错误率 $\epsilon = \sum w_i (y_i \neq \hat{y}_i)$
  4. 计算学习率 $\alpha = \frac{1}{2} \log(\frac{1-\epsilon}{\epsilon})$
  5. 更新权重 $w_i = w_i \cdot \exp(-\alpha y_i \hat{y}_i)$
  6. 重复直至达到最大迭代次数
- **最终预测**：$\hat{y} = \text{sign}(\sum \alpha_t f_t(x))$

## 视频116：GBDT提升算法流程（9）

### 知识点
- **GBDT（Gradient Boosting Decision Tree）**：
  - 基于梯度下降的提升方法
  - 每轮学习器拟合前一轮的残差（负梯度）
- **算法步骤**：
  1. 初始化 $f_0(x) = \text{常数}$
  2. 计算残差 $r_i = y_i - f_m(x_i)$
  3. 训练决策树拟合残差
  4. 更新 $f_{m+1}(x) = f_m(x) + \nu \cdot \text{Tree}(x)$
  5. 重复直至收敛
- **学习率$\nu$**：控制每棵树的贡献，防止过拟合

## 视频118：模型提前停止策略（11）

### 知识点
- **早停（Early Stopping）**：
  - 监控验证集误差
  - 当验证误差不再下降时停止训练
  - 防止过拟合
- **实现方式**：
  - Sklearn的GBDT：`n_iter_no_change` 参数
  - XGBoost/LightGBM：`early_stopping_rounds` 参数
- **代码示例**：
  ```python
  from xgboost import XGBClassifier
  xgb = XGBClassifier(early_stopping_rounds=10)
  xgb.fit(X_train, y_train, eval_set=[(X_val, y_val)])
  ```

## 视频119：停止方案实施（12）

### 知识点
- **早停实现细节**：
  1. 划分训练集和验证集
  2. 每轮迭代后评估验证集误差
  3. 如果误差连续N轮不下降，停止训练
  4. 保存最佳模型
- **最佳轮次选择**：`best_iteration` 属性
- **学习率与迭代次数的权衡**：
  - 小学习率 + 多轮迭代
  - 大学习率 + 少轮迭代

## 视频120：堆叠模型（13）

### 知识点
- **Stacking实战**：
  ```python
  from sklearn.ensemble import StackingClassifier
  from sklearn.linear_model import LogisticRegression
  from sklearn.svm import SVC
  from sklearn.tree import DecisionTreeClassifier
  from sklearn.ensemble import RandomForestClassifier
  
  # 定义基学习器
  estimators = [
      ('rf', RandomForestClassifier(n_estimators=100)),
      ('svc', SVC(probability=True)),
      ('dt', DecisionTreeClassifier(max_depth=5))
  ]
  
  # 定义元学习器
  final_estimator = LogisticRegression()
  
  # 创建堆叠分类器
  stacking = StackingClassifier(
      estimators=estimators,
      final_estimator=final_estimator,
      cv=5
  )
  ```
- **效果分析**：Stacking通常比单个模型效果更好
