## 目标

从多数据源获取 A 股全市场股票的行情数据、基本面数据、资金流数据，为打分模块提供标准化输入。

***

## 数据源与优先级

| 优先级 | 数据源               | 用途        | 备注       |
| --- | ----------------- | --------- | -------- |
| 主源  | 东方财富 API          | 实时行情、财务指标 | 盘后高峰可能超时 |
| 备源1 | 新浪财经 API          | 行情数据备份    | 字段较少     |
| 备源2 | 同花顺 API           | 财务数据备份    | <br />   |
| 降级  | 热门龙头股池（本地 Top 50） | 全部不可用时启用  | 保证不空跑    |

> **禁止**绕过 `data_fetcher.py` 直接调用上述 API。

## 收集的指标清单

参考 `投资知识/数据收集关注指标.md`，核心指标分三类：

### 1. 基本面指标（每季度更新）

> 基本面指标分两类：**质量筛查指标**用于"一票否决"（快速排除差公司，不追求全面），**估值评估指标**用于打分排序（评估"好公司现在买贵不贵"）。

#### 1a. 质量筛查指标 —— 筛选用，少而精

> 原则：只用最核心的几个指标快速排除"绝对不行"的公司，宁缺毋滥。

| 指标     | 字段名                 | 筛选用途           | 否决标准                  |
| ------ | ------------------- | -------------- | --------------------- |
| ROE    | `roe`               | 连赚钱的能力都没有？     | ROE < 3% 且连续3年下滑 → 排除 |
| 净利润增长率 | `net_profit_growth` | 生意是不是在萎缩？      | 连续2年负增长 → 排除          |
| 自由现金流  | `free_cash_flow`    | 赚的是纸面利润还是真金白银？ | 连续2年为负 → 排除           |
| 资产负债率  | `debt_ratio`        | 会不会被债压垮？       | 超过行业阈值（自适应）→ 排除       |

#### 1b. 估值评估指标 —— 打分组用，全面参考

> 这些指标包含股价成分，不属于"纯基本面"，不用于筛查，而用于打分阶段判断"现在买贵不贵"。

| 指标   | 字段名              | 用途                    |
| ---- | ---------------- | --------------------- |
| 市盈率  | `pe`             | 估值水平（PE低不一定好，需结合行业增速） |
| 市净率  | `pb`             | 估值水平（银行/地产更看重PB）      |
| 股息率  | `dividend_yield` | 稳健回报（高股息率适合防守型标的）     |
| 净利润  | `net_profit`     | 绝对盈利规模                |
| 营业收入 | `revenue`        | 业务规模                  |

### 2. 技术面指标（每日更新）

| 指标      | 字段名               | 用途                                |
| ------- | ----------------- | --------------------------------- |
| 20日均线   | `ma20`            | 趋势判断（核心）                          |
| 10日均线   | `ma10`            | 中短期趋势判断                           |
| 5日均线    | `ma5`             | 短期趋势判断                            |
| 5日均量    | `vol_ma5`         | 量能判断                              |
| 换手率     | `turnover_rate`   | 市场关注度（要求 3%-15%）                  |
| 近5日涨幅   | `pct_5d`          | 短期动量                              |
| 近20日涨幅  | `pct_20d`         | 中期动量                              |
| 前一日尾盘涨幅 | `tail_pct`        | 尾盘拉升信号（要求 3%-5%）                  |
| 流通市值    | `circ_market_cap` | 盘口筛选（要求 50亿-500亿）                 |
| 成交量趋势   | `vol_trend`       | 连续性放量判断（要求近3日成交量逐日放大）             |
| 均线多头排列  | `ma_alignment`    | K线形态健康度（股价需站上 MA5/MA10/MA20 三条均线） |

### 3. 资金面指标（每日更新，下周扩展）

| 指标      | 字段名          | 用途        |
| ------- | ------------ | --------- |
| 北向资金净流入 | `north_flow` | 外资动向（待开发） |
| 主力净流入   | `main_flow`  | 主力资金动向    |

## 执行步骤

```
Step 1: 检查 stock_list_cache.json 是否在 7 天有效期内
  ├─ 有效 → 跳过 Step 2，直接用缓存列表
  └─ 过期 → 进入 Step 2

Step 2: 调用 data_fetcher.fetch_stock_list() 获取全 A 股列表（~5500只）
  └─ 失败 → 降级到热门龙头股池（Top 50）

Step 3: 对每只股票调用 data_fetcher.fetch_stock_data(code)
  ├─ 主源成功 → 返回数据
  ├─ 主源失败 → 间隔 2s → 4s → 8s 重试
  └─ 重试3次仍失败 → 切换备源 → 全部失败 → 跳过该股票并记录日志

Step 4: 预过滤（以下条件全部需同时满足，分两轮筛查）
  ├─ 第一轮：质量筛查（基本面一票否决，排除绝对不行的公司）
  │   ├─ ROE ≥ 3% 或未连续3年下滑
  │   ├─ 净利润增长率 未连续2年负增长
  │   ├─ 自由现金流 未连续2年为负
  │   └─ 资产负债率 低于行业阈值（自适应）
  ├─ 第二轮：形态筛查（量价形态门槛）
  │   ├─ 排除 ST/*ST 股票
  │   ├─ 排除停牌股票
  │   ├─ 流通市值 ∈ [50亿, 500亿]
  │   ├─ 前一日尾盘涨幅 ∈ [3%, 5%]
  │   ├─ 换手率 ∈ [3%, 15%]
  │   ├─ 近3日成交量逐日放大
  │   └─ 股价站上 MA5、MA10、MA20 三条均线
  └─ 两轮全部通过 → 进入候选池 → 传递给 stock-scoring 打分

Step 5: 输出标准化 DataFrame，字段名见上方指标清单
  └─ 传递给 stock-scoring 子流程
```

## 行业识别体系（两级分类）

> 行业识别是自适应阈值的基础，分类越精细，打分越准确。采用"两级分类"：一级分类用于大方向路由，二级分类用于精细化阈值匹配。

### 识别方式

1. **关键词匹配**（股票名称中包含的关键词）→ 初步定位
2. **代码前缀辅助**（600主板/000深成指/300创业板/688科创板）→ 补充判断
3. **东方财富行业API**（后续接入）→ 精准识别，替代关键词匹配

## 注意事项

1. **行业识别必须在此阶段完成**：采用上述"两级分类"体系，优先关键词匹配，后续接入东方财富行业API做精准识别。识别结果同时打上 `industry_level1` 和 `industry_level2` 标签。
2. **行业自适应阈值必须配合二级分类**：仅用一级分类（如"金融"）做阈值不够精细，必须用二级分类（如"金融.股份制银行"）才能给出准确阈值。
3. **缓存文件不得篡改**：`stock_list_cache.json` 内含时间戳，过期后由系统自动刷新。
4. **日志必须记录**：每次 API 切换、缓存命中/过期、降级事件都要 `print` 带时间戳的日志。
5. **预过滤条件为硬性门槛**：两轮筛查（质量筛查 + 形态筛查）是"与"的关系，任一条件不满足即排除，不进入打分环节。
