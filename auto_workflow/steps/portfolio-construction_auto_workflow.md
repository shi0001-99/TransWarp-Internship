---

## 目标

接收量化打分模块输出的 Top10 股票及其详细评分，基于凯利公式计算最优持仓占比，构建买入持仓方案，为卖点确定环节提供基础。

---

## 输入

从 `stock-scoring` 环节接收以下数据：

| 输入项 | 格式 | 说明 |
|--------|------|------|
| Top10 股票列表 | JSON | 股票代码、名称、综合得分、各项小分 |
| 行业标签 | 字符串 | 一级.二级分类（如"科技.AI软件"） |
| 买入建议 | 布尔 | 评分环节的买入信号判断 |
| 历史胜率数据 | 数值 | 近20次同类信号的盈利比例 |

---

## 组合构建体系

### 一、凯利公式计算最优仓位

```
f* = (p × b - q) / b

其中：
  f* = 最优仓位比例
  p  = 历史胜率（近20次同类信号中盈利次数 / 20）
  q  = 1 - p （亏损概率）
  b  = 赔率（平均盈利金额 / 平均亏损金额）
```

### 二、仓位约束规则

| 约束 | 规则 | 说明 |
|------|------|------|
| 单票上限 | ≤ 30% | 防止过度集中 |
| 单票下限 | ≥ 5% | 防止仓位过轻 |
| 行业集中度 | 单行业 ≤ 40% | 强制分散，避免赛道风险 |
| 总仓位上限 | 100% | 满仓时不得超过此限 |
| 最小持仓数 | ≥ 5 只 | 保证分散化 |

### 三、仓位分配流程

```
Step 1: 读取 Top10 股票列表及其评分
  ├─ 剔除买入信号为 False 的股票
  └─ 若剩余 < 5 只 → 从观察池补入高分标的

Step 2: 计算每只股票的凯利仓位
  ├─ 获取该股票的历史胜率 p
  │   └─ 近20次同类信号（同行业+同技术形态）的胜率
  ├─ 获取该股票的赔率 b
  │   └─ 近20次同类信号的平均盈利 / 平均亏损
  ├─ 计算 f* = (p × b - q) / b
  └─ 应用约束规则，截断到 [5%, 30%]

Step 3: 行业分散度调整
  ├─ 统计各行业仓位占比
  ├─ 单行业 > 40% → 按得分从低到高削减
  └─ 削减后的仓位重新分配给其他行业

Step 4: 归一化处理
  ├─ 计算总仓位 = 所有单票仓位之和
  ├─ 若总仓位 > 100% → 等比例缩小
  └─ 若总仓位 < 100% → 保留现金或加仓至优质标的

Step 5: 输出最终持仓方案
```

### 四、动态仓位调整

#### 大盘择时调整

```
上证指数状态          总仓位上限
─────────────────────────────────
> MA20（牛市）         100%
跌破 MA20 但 > MA60   50%
跌破 MA60（熊市）      0%（空仓观望）
```

#### 波动率调整

```
波动率（近20日）      单票仓位系数
─────────────────────────────────
< 15%（低波动）        × 1.2（可适当加仓）
15%-30%（正常）        × 1.0
> 30%（高波动）        × 0.7（降低仓位）
```

## 执行步骤

```
Step 1: 接收 stock-scoring 输出的 Top10 结果

Step 2: 过滤买入信号 = True 的股票
  └─ 补足到至少5只，按综合得分排序

Step 3: 逐股票计算凯利仓位
  ├─ 查询历史胜率 p 和赔率 b
  ├─ 计算 f* = (p × b - q) / b
  └─ 截断到 [5%, 30%]

Step 4: 行业分散度调整
  ├─ 统计行业占比
  ├─ 单行业 > 40% 时削减
  └─ 重新分配削减仓位

Step 5: 大盘择时调整
  ├─ 判断上证指数与 MA20/MA60 的关系
  └─ 调整总仓位上限

Step 6: 波动率调整
  ├─ 计算各股票近20日波动率
  └─ 应用波动率系数

Step 7: 归一化 → 输出最终持仓方案
```

## 风控检查清单

| # | 检查项 | 规则 | 不通过处理 |
|---|--------|------|-----------|
| C1 | 单票仓位上限 | ≤ 30% | 超限截断到 30% |
| C2 | 单票仓位下限 | ≥ 5% | 不足则补入观察池标的 |
| C3 | 行业集中度 | 单行业 ≤ 40% | 按得分从低到高削减 |
| C4 | 持仓数量 | ≥ 5 只 | 从观察池补入 |
| C5 | ST/停牌检查 | 不得持有 | 立即剔除 |
| C6 | 流动性检查 | 日均成交额 ≥ 5000万 | 立即剔除 |
| C7 | 总仓位上限 | ≤ 100% | 等比例缩小 |

## 注意事项

1. **凯利公式的局限性**：历史胜率和赔率基于过去数据，不代表未来。建议人工审阅后再执行。
2. **仓位不等于执行**：本环节输出的是"目标仓位"，实际买入需由交易模块按盘中价格分批次执行。
3. **动态调整频率**：每周五收盘后重新计算仓位，仅在得分变化超过 10 分或行业集中度超标时触发调仓。
4. **现金储备**：建议保留至少 10% 现金应对极端行情（单日跌幅 > 3% 时加仓机会）。
5. **硬约束 H1**：行业自适应必须使用二级分类，禁止用一级分类做仓位分配。
